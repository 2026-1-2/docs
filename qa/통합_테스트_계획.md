# 통합 테스트 계획 (Integration Test Plan)

> 작성: 이상민 (QA) · 대상: 드론 버티포트 CCTV 통합 감시 시스템

## 1. 목적
구성 요소(IP Camera → MediaMTX → recorder/mmp-server → client)가 결합된 상태에서
사용자 요구사항과 설계가 end-to-end로 동작하는지 검증한다.

## 2. 테스트 대상 구성요소
| 구성요소 | 역할 | 비고 |
|---|---|---|
| IP Camera (RTSP/ONVIF) | 영상 소스, PTZ | 2~4대 |
| MediaMTX | RTSP → WebRTC/HLS 변환 | media-server |
| video-recorder | FFmpeg 24h 연속 녹화 | codec copy |
| mmp-server | REST API, ONVIF PTZ, VOD 서빙 | |
| client | 웹 관제 UI | React + WHEP + hls.js |
| Nginx | 리버스 프록시 | infra |

## 3. 테스트 범위
- 실시간 스트리밍 (WebRTC/WHEP)
- 녹화 저장 및 순환 삭제 (FFmpeg)
- 녹화 영상 검색/재생 (HLS)
- PTZ 원격 제어 (ONVIF)
- 카메라 등록/삭제 (REST API)
- 장애 복구 (프로세스 재시작, 네트워크 단절)

## 4. 테스트 환경
- Docker Compose 단일 호스트 배포
- 카메라 2대 사전 등록 + 1대 시연 중 등록
- 측정 도구: 브라우저 DevTools(WebRTC stats), `ffprobe`, `docker stats`

## 5. 합격 기준 (Exit Criteria)
- 실시간 지연 ≤ 0.5초 (WebRTC)
- 24시간 연속 녹화 중 누락 구간 없음
- 디스크 사용량 임계치 초과 시 오래된 세그먼트 자동 삭제 동작
- PTZ 명령 후 1초 이내 카메라 반응
- 모든 Critical/High 결함 수정 완료
