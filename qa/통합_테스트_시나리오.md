# 통합 테스트 시나리오 / 체크리스트

> 작성: 이상민 (QA) · 6/2 Demo 시나리오와 연동

각 시나리오는 사전조건 → 절차 → 기대결과 순으로 기술한다.
체크박스는 최종 회귀 검증 기준.

## TC-01 실시간 관제 (WebRTC)
- 사전조건: 카메라 1대 등록, MediaMTX 기동
- 절차: 대시보드 진입 → 카메라 패널 로드
- 기대결과: 0.5초 이하 지연으로 라이브 영상 재생
- [x] 단일 카메라 재생
- [x] 다중 카메라 동시 재생 (그리드)
- [x] 패널 레이아웃 프리셋 전환 시 스트림 유지

## TC-02 PTZ 제어 (ONVIF)
- 사전조건: PTZ 지원 카메라 선택
- 절차: PTZ 컨트롤/방향키 입력
- 기대결과: 1초 이내 Pan/Tilt/Zoom 반영
- [x] Pan/Tilt 동작
- [x] Zoom 동작
- [x] 비-PTZ 카메라 선택 시 컨트롤 비활성

## TC-03 24시간 연속 녹화 (FFmpeg)
- 사전조건: recorder 기동
- 절차: 24시간 방치 후 세그먼트 점검
- 기대결과: 누락 구간 없이 분할 저장
- [x] 세그먼트 연속성 (`ffprobe` 타임스탬프 확인)
- [x] 프로세스 강제 종료 후 자동 재시작
- [x] 재시작 후 녹화 재개

## TC-04 디스크 순환 삭제
- 사전조건: 디스크 임계치 근접 상태 모의
- 절차: 임계치 초과 유도
- 기대결과: 오래된 세그먼트부터 자동 삭제
- [x] 임계치 초과 시 삭제 트리거
- [x] 최신 녹화 보존

## TC-05 녹화 영상 검색/재생 (HLS)
- 사전조건: 과거 녹화본 존재
- 절차: History 화면 → 날짜/카메라 선택 → 재생
- 기대결과: 타임라인 탐색 가능
- [x] 날짜·카메라별 조회
- [x] 탐색(seek)/되감기
- [x] 존재하지 않는 구간 예외 처리

## TC-06 카메라 등록/삭제 (REST API)
- 절차: Device Management → 등록(이름/타입/스트림 URL) → 목록 확인
- [x] 등록 후 목록 반영
- [x] 잘못된 스트림 URL 입력 시 에러 핸들링
- [x] 삭제 후 대시보드에서 제거
