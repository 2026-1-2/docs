# 위협 모델 분석 (Threat Model)

> 작성: 이상민 (보안/인프라) · 제한조건 "안전성" 대응 문서

## 1. 자산 (Assets)
- 실시간/녹화 영상 스트림 (개인정보·초상권 포함 가능)
- 카메라 제어 권한 (PTZ)
- 관제 시스템 접근 권한 / 관리자 계정
- 시스템 로그 및 메타데이터

## 2. 신뢰 경계 (Trust Boundaries)
```
[외부 인터넷] ── Nginx 리버스 프록시 ──┬── client(웹)
                                       ├── mmp-server(REST API)
                                       └── MediaMTX(시그널링/스트림)
[관제 내부망] ── PoE 스위치 ── IP Camera (RTSP/ONVIF)
```
- 카메라 내부망은 외부망과 분리.
- 외부 진입점은 Nginx로 단일화.

## 3. 위협 (STRIDE 기반)
| 위협 | 시나리오 | 대응 |
|---|---|---|
| Spoofing | 비인가 사용자의 관제 접근 | 관리자 인증, 세션 관리 |
| Tampering | 스트림/요청 변조 | TLS, API 입력 검증 |
| Repudiation | 행위 부인 | 시스템 로그 기록 |
| Information Disclosure | 영상 무단 열람 | 접근 제어, 내부망 분리, RTSP 인증 |
| Denial of Service | 스트림/엔드포인트 과부하 | 프록시 단 제한, 채널 수 관리 |
| Elevation of Privilege | 권한 상승 | 최소 권한, 카메라 원격 추가 비활성 |

## 4. 핵심 완화 조치
- Nginx 리버스 프록시를 통한 접근 통제 및 외부 표면 최소화
- 카메라/RTSP 스트림 인증, 관제망–외부망 분리
- recorder의 카메라 원격 추가 미지원 → 현장 물리 설치만 허용(공격 표면 축소)
- 모든 의존 라이브러리 오픈소스 라이선스 정품 사용 (제한조건 윤리성)

## 5. 잔여 위험 및 권고
- TLS 인증서 운영(갱신) 자동화 권고
- 관리자 계정 다중화 시 RBAC 도입 검토
- 영상 보관 기간/접근 로그 정책 문서화 (사생활 보호)
