## 🗒️ 회의 내용
### 📎 안건 1: HW Environment 확인
- **논의 내용**:
  - 서버 및 카메라 HW 확인 및 수령 완료
  - 하드웨어 구성 논의
    - 1안. 서버를 2대 사용 (카메라1 + 카메라2 + 영상 Stream 서버) <-> 스위치허브 <-> (인터넷) <-> 메인서버(Backend)
      - Production 환경에 적합: 카메라 수가 많을 경우에 적합.
      - 전국 각지에 분포된 비행장 CCTV 영상을 수합하는 경우 등..
    - 2안(채택). 서버를 1대 사용 (카메라1 + 카메라2) <-> 스위치허브 <-> (인터넷) <-> 메인서버
      - 종합설계프로젝트2 개발 환경에 적합: 카메라 수가 적을 경우에 적합.
      - 단, 메인서버에서 카메라 영상을 Stream 형태로 수집하도록 함 -> 차후 카메라 대신 Stream 서버가 들어와도 작동할 수 있게 하기 위함.
      - 1안으로의 변경 시, 백엔드 서버에서 영상 Stream 서버 Branch 진행.
      - Docker 사용하여 Containerization 진행 -> 차후 서비스 확장 및 HW Environment 변경 시 유연하게 대응할 수 있도록 함.

### 📎 안건 2: 프론트엔드 디자인 피드백
