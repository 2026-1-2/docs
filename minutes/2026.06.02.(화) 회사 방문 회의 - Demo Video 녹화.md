## 영상 시나리오
아래 흐름이면 시연 영상으로 자연스럽습니다. “현장 설치 → 시스템 접속 → 카메라 등록 → 실시간 관제 → 이벤트 발생 → 기록 조회” 순서라 보는 사람이 기능 목적을 바로 이해할 수 있습니다.

**시연 영상 시나리오**

1. **현장 소개**
    - 드론 이착륙장 또는 촬영 대상 공간을 먼저 보여줌
    - 고정형/PTZ 카메라가 설치된 위치를 짧게 촬영
    - “이 시스템은 드론 이착륙장 주변을 실시간으로 감시하고 이벤트를 기록하는 관제 시스템”이라고 설명
2. **로그인 & 관제 환경 소개**
    - 큰 모니터에 MMP 메인 화면을 띄운 장면 촬영
    - 관리자 계정으로 로그인
    - 인증 후 메인 대시보드로 진입되는 흐름 보여줌
    - 16:9 대형 모니터 기준으로 CCTV 화면, 날씨/풍속, 지도, PTZ 컨트롤, 이벤트 영역이 보이는지 확인
3. **CCTV 등록**
    - Device Management 또는 카메라 등록 UI로 이동
    - 카메라 이름, 타입, 스트림 URL 입력
    - 등록 후 목록에 추가되는지 확인
4. **메인 대시보드 확인 (X)**
    - 등록한 CCTV가 메인 대시보드에 표시되는지 확인
    - 실시간 영상이 재생되는 장면 보여줌
    - 카메라 여러 개가 있을 때 레이아웃이 자동 정리되는 모습도 짧게 보여주면 좋음
5. **PTZ 조작 시연 (0)**
    - PTZ 지원 카메라를 선택
    - 우측 하단 PTZ 컨트롤 또는 키보드 방향키로 카메라 방향이 바뀌는지 보여줌
    - 선택한 CCTV가 어떤 카메라인지 화면에서 식별되는 부분도 같이 보여줌
6. **Object Detection 테스트 (0)**
    - 사람이 CCTV 앞을 지나가는 장면 촬영
    - 실시간 알림 toast 또는 알림 아이콘에 감지 이벤트가 표시되는지 확인
    - 알림 클릭 시 감지 시간, 이미지/스냅샷 정보가 모달로 표시되는 흐름 시연
7. **이벤트 로그 확인 (0)**
    - System Logs 또는 이벤트 로그 화면으로 이동
    - 방금 발생한 Object Detection 이벤트가 기록되었는지 확인
    - 시간, 카메라, 이벤트 타입, 메시지가 남는지 보여줌
8. **과거 영상 조회 (0)**
    - History/VOD 화면으로 이동
    - 카메라와 날짜를 선택
    - 녹화 영상 목록 조회
    - 특정 영상을 재생하거나 다운로드 가능한 흐름을 보여줌
9. **마무리**
- 다시 메인 대시보드로 돌아와 실시간 관제 화면을 보여줌
- “카메라 등록, 실시간 관제, PTZ 조작, 객체 감지 알림, 이벤트 기록, 과거 영상 조회까지 하나의 관제 흐름으로 연결됨”이라고 정리

**촬영 팁**

- 시연 전에 카메라 2개는 미리 등록해두고, 영상에서는 1개만 새로 등록하는 방식이 좋습니다.
    - 아얘 3개 모두 영상에서 새로 등록하는 것은 어떨까요?
        - 현재 MediaMTX 는 recorder 와 설정 파일을 공유하도록 되어 있습니다.
        - Recorder 쪽은 카메라 실시간 추가를 지원하지 않습니다.
            - 일반적으로 CCTV Recorder(DVR/NVR)는 현장에 설치함을 고려
            - 이착륙장의 CCTV 설정을 변경(추가/삭제)해야 하는 경우는 물리적으로 CCTV를 추가/제거하는 상황에 해당
            → 어차피 사람이 들어가고, 현장 테스트도 해야 하니까, Recorder에 대한 카메라 원격 추가/제어 기능은 불필요하다고 판단
        - 2대는 등록 / 1대만 새로 추가하는 방법도 가능은 할 것 같은데, 배포 후 mediaMTX 설정을 수동으로 바꿔줘야 하는 만큼 영상 촬영 중 실수가 우려됩니다..
- Object Detection은 실패하면 영상 흐름이 끊기기 쉬우니, 감지 이벤트 mock 또는 백엔드 테스트 이벤트를 보낼 수 있는 방법도 백업으로 준비하는 게 좋습니다.
- 과거 영상 조회는 실제 파일이 있어야 하므로, 촬영 전에 해당 날짜/카메라의 VOD 파일이 조회되는지 미리 확인해두는 게 안전합니다.
    - 5월 28일 촬영된 영상을 활용
