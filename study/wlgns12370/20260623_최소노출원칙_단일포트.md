# 프롬프트
> MMP의 최소 노출 원칙과 단일 포트 구조를 설명해줘.

## 최소 노출 원칙이란

시스템이 외부에 노출하는 **공격 표면**을 최소화하는 보안 원칙.

---

## MMP의 적용

외부 노출 포트: **단 1개 (8002)**

```
인터넷/관리자 PC → :8002 (nginx) → 내부 서비스로 라우팅
```

---

## 내부 포트 차단 현황

| 포트 | 외부 접근 | 이유 |
|---|---|---|
| 3306 (MySQL) | 차단 | DB 직접 접근 차단 |
| 9997 (MediaMTX API) | 차단 | 내부 제어 API |
| 8554 (RTSP) | 카메라망만 | 카메라 전용 네트워크 |

---

## 보안 효과

- 외부 공격자가 DB에 직접 접근 불가
- 단일 진입점(8002)에 방화벽·WAF 집중 적용 가능
