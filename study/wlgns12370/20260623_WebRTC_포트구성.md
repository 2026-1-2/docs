# 프롬프트
> WebRTC 스트리밍에 사용하는 포트 구성을 정리해줘.

## MediaMTX WebRTC 포트

| 포트 | 프로토콜 | 역할 |
|---|---|---|
| 8889 | HTTP/WS | WebRTC 시그널링 (SDP Offer/Answer) |
| 8189/udp | UDP (SRTP) | WebRTC ICE 미디어 — 주경로 |
| 8189/tcp | TCP | WebRTC ICE TCP Fallback |
| 8888 | HTTP | HLS 폴백 스트리밍 |

---

## nginx 단일 포트 노출

외부에는 8002 하나만 열림. nginx가 경로 기반으로 내부 라우팅:

```
:8002/         → React SPA
:8002/api/     → mmp-server
:8002/webrtc/  → MediaMTX :8889
```

---

## PUBLIC_HOST가 중요한 이유

WebRTC ICE Candidate에 브라우저가 접근 가능한 실제 IP가 포함되어야 함.  
컨테이너 내부 IP가 포함되면 브라우저에서 연결 불가.

```env
PUBLIC_HOST=192.168.0.100
```
