# 프롬프트
> WebRTC에서 SDP(Session Description Protocol)가 무엇인지, Offer/Answer 교환이 어떻게 이루어지는지 설명해줘.

## SDP란

WebRTC 연결을 수립할 때 **미디어 세션 정보를 기술하는 텍스트 형식**.  
코덱, 해상도, 대역폭, ICE 후보 등 연결에 필요한 모든 정보를 담는다.

---

## SDP 주요 필드

```
v=0                          # 버전
o=- 123456 2 IN IP4 127.0.0.1  # 세션 식별자
s=-                          # 세션 이름
t=0 0                        # 시간
m=video 9 UDP/TLS/RTP/SAVPF 96  # 미디어 타입
a=rtpmap:96 H264/90000       # 코덱 정보
a=candidate:... typ host     # ICE 후보
```

---

## Offer/Answer 흐름

```
React Client                    MediaMTX
     |                               |
     |-- POST /webrtc/cam-01 ------> |  (SDP Offer 전송)
     |                               |
     |<-- 200 OK (SDP Answer) ------ |  (Answer 반환)
     |                               |
     |<====== RTP/SRTP 미디어 ======>|  (스트리밍 시작)
```

---

## MMP에서의 역할

- 클라이언트가 `:8889`에 POST → SDP Offer 전송
- MediaMTX가 SDP Answer 반환
- 이후 ICE 후보 교환 → DTLS 핸드셰이크 → SRTP 미디어 전송
