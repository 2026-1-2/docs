# 프롬프트
> MMP 시스템 배포 및 운영 절차를 단계별로 설명해줘.

## 시스템 요구사항

| 항목 | 최소 | 권장 |
|---|---|---|
| OS | Docker 지원 Linux | Ubuntu 22.04 LTS |
| CPU | 4코어 | 8코어 이상 |
| RAM | 4 GB | 8 GB 이상 |
| 스토리지 | SSD 20 GB + HDD | HDD 1 TB 이상 |
| 네트워크 | 100 Mbps | 1 Gbps |

---

## 배포 절차

```bash
git clone https://github.com/2026-1-2/mmp-server
cd mmp-server/infra
cp .env.example .env          # PUBLIC_HOST, JWT_SECRET 등 설정
sudo mkdir -p /hdd/mmp-data/mysql /hdd/mmp-data/recordings
docker compose up -d
docker compose ps
```
