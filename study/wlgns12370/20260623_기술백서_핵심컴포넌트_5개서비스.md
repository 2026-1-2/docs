# 프롬프트
> MMP 시스템을 구성하는 5개 Docker 컨테이너를 설명해줘.

## 5개 컨테이너 구성

| 컨테이너 | 이미지 | 외부 포트 | 역할 |
|---|---|---|---|
| mmp-api | `ghcr.io/2026-1-2/mmp-server:latest` | 내부 | REST API, 카메라 관리, JWT 인증 |
| mmp-client | `ghcr.io/2026-1-2/client:latest` | 8002 | React SPA + nginx 리버스 프록시 |
| mmp-mediamtx | `bluenviron/mediamtx:latest` | 8554, 8189 | RTSP → WebRTC/HLS 미디어 서버 |
| mmp-recorder | `video-recorder:latest` | 내부 | RTSP 스트림 → HDD 녹화 (MP4) |
| mmp-mysql | `mysql:8.0` | 내부 | 카메라·이벤트·사용자 메타데이터 |

---

## 서비스 시작 순서

- `mmp-api`는 MySQL healthcheck 통과 후 시작 (`depends_on: condition: service_healthy`)
- MySQL 초기화까지 약 10~30초 소요
