# 프롬프트
> MediaMTX의 동작 원리를 설명해줘.

## MediaMTX란

멀티프로토콜 미디어 프록시/서버. 단일 인스턴스에서 RTSP 수신과 WebRTC·HLS 배포를 동시에 처리.

- 구 이름: rtsp-simple-server
- MMP 사용 이미지: `bluenviron/mediamtx:latest`

---

## 핵심 역할

```
RTSP 카메라 스트림 수신
        ↓
  MediaMTX (변환/라우팅)
        ↓
WebRTC :8889  |  HLS :8888  |  RTSP :8554 재배포
```

---

## 경로(Path) 개념

각 카메라는 하나의 경로로 관리됨:

```
/cam-01  →  rtsp://192.168.0.101:554/stream
/cam-02  →  rtsp://192.168.0.102:554/stream
```

클라이언트는 `ws://server:8889/cam-01` 형태로 접근.

---

## mmp-server와 연동

카메라 추가 시 mmp-server → MediaMTX REST API(:9997) 호출 → 경로 등록  
**서버 재시작 없이 런타임에 카메라 핫플러그 가능**
