# 프롬프트
> 주요 카메라 제조사별 RTSP URL 형식을 정리해줘.

## RTSP URL 기본 형식

```
rtsp://[user]:[pass]@[host]:[port]/[path]
```

---

## 제조사별 RTSP URL 예시

| 제조사 | RTSP URL 형식 |
|---|---|
| Hikvision | `rtsp://admin:pw@192.168.0.101:554/Streaming/Channels/101` |
| Dahua | `rtsp://admin:pw@192.168.0.101:554/cam/realmonitor?channel=1&subtype=0` |
| Axis | `rtsp://admin:pw@192.168.0.101/axis-media/media.amp` |
| 삼성/한화 | `rtsp://admin:pw@192.168.0.101:554/profile2/media.smp` |
| ONVIF 자동 | ONVIF Discovery로 URL 자동 검색 가능 |

---

## 채널 / 서브스트림

대부분의 카메라는 **메인스트림**과 **서브스트림** 제공:

```
메인스트림: /Streaming/Channels/101  (고화질, 고용량)
서브스트림: /Streaming/Channels/102  (저화질, 저용량)
```

영상관제 모니터링에는 서브스트림, 녹화에는 메인스트림 사용 권장.

---

## MMP 설정 예시

```conf
# config/camera/cam1.conf
cam_ip        192.168.0.101;
cam_port      554;
cam_rtsp_path Streaming/Channels/101;
```
