# 프롬프트
> MediaMTX에서 카메라 경로를 런타임에 동적으로 등록하는 방법을 설명해줘.

## 기존 방식의 문제

설정 파일에 카메라 등록 후 서버 재시작 필요 → 카메라 추가마다 서비스 중단.

---

## MediaMTX REST API로 동적 등록

```
POST http://mediamtx:9997/v3/config/paths/add/{cameraId}

{
  "source": "rtsp://192.168.0.101:554/stream",
  "sourceOnDemand": true
}
```

- `sourceOnDemand: true` → 클라이언트가 접근할 때만 RTSP 연결 (리소스 절약)

---

## 카메라 삭제

```
DELETE http://mediamtx:9997/v3/config/paths/remove/{cameraId}
```

---

## mmp-server 처리 흐름

```
카메라 추가 요청 → DB 저장 → MediaMTX API 호출 → 즉시 스트리밍 가능
```
