# 프롬프트
> MMP 온프레미스 영상관제 플랫폼의 핵심 기술 결정 사항을 최종 요약해줘.

## 3가지 핵심 기술 결정

### 1. WebRTC 실시간 스트리밍

- 기존 HLS 5~30초 지연 → WebRTC로 0.1~0.5초로 단축
- MediaMTX의 동적 경로 API로 카메라 핫플러그 관리
- HLS 자동 폴백으로 방화벽 환경 대응

### 2. Docker Compose + GHCR 기반 배포

- 5개 서비스를 단일 스택으로 구동 (`docker compose up -d`)
- GHCR 이미지 등록으로 소스 없이 서버 이전 가능
- GitHub Actions CI/CD로 push → 자동 배포, 이미지 태그로 즉시 롤백

### 3. ONVIF/RTSP 범용 호환

- 특정 벤더 종속 없이 표준 프로토콜로 카메라 연동
- ONVIF PTZ 제어 + RTSP 전용 녹화 통합 지원

## 핵심 기술 요약표

| 기술 | 컴포넌트 | 효과 |
|---|---|---|
| WebRTC ICE/SRTP | MediaMTX :8889/:8189 | 1초 미만 저지연 스트리밍 |
| HLS 자동 폴백 | MediaMTX :8888 | 방화벽 환경 호환성 |
| Docker Compose | 5개 컨테이너 | 단일 명령 배포 |
| GHCR CI/CD | GitHub Actions | 자동 빌드·배포·롤백 |
| Dual JWT | mmp-server | 세션 보안 강화 |
| ONVIF + RTSP | mmp-server + recorder | 범용 카메라 지원 |
| 최소 노출 원칙 | nginx :8002 | 공격 표면 최소화 |
