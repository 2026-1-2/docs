# 프롬프트
> MMP에서 배포 후 문제가 생겼을 때 롤백하는 방법을 설명해줘.

## 롤백이 쉬운 이유

GHCR에 **이전 이미지 태그가 보존**되므로  
소스 revert + 재빌드 없이 이미지 태그만 바꿔 즉시 롤백 가능.

---

## 롤백 방법

```bash
# docker-compose.yml에서 태그 변경
image: ghcr.io/2026-1-2/mmp-server:sha-abc1234

docker compose up -d
```

---

## GHCR에서 이미지 태그 확인

GitHub → 해당 레포 → Packages 탭 → 이미지 클릭 → 태그 목록 확인

---

## 롤백 소요 시간

```
이미지 pull: ~수십 초
docker compose up: ~30초
총 소요: 약 1분 이내
```

소스 재빌드(수 분)보다 훨씬 빠른 복구 가능.
