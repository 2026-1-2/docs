# 프롬프트
> MMP의 보안 아키텍처를 설명해줘.

## 최소 노출 원칙

- 외부 노출 포트는 **nginx 단일 포트 8002**뿐
- nginx가 경로 기반 내부 라우팅: `/` → React, `/api` → mmp-server

---

## 이중 토큰 (Dual-Token) JWT

```
Access Token  : 단기 유효 | JWT_SECRET으로 서명
Refresh Token : 장기 유효 | JWT_REFRESH_SECRET으로 별도 서명
```
- 탈취 시 피해 범위를 Access Token 만료 시간 이내로 제한

---

## 보안 권고

- `JWT_SECRET`, `DB_PASSWORD`는 `openssl rand -hex 32`로 생성
- `.env` 파일은 절대 git에 커밋하지 않음 (`.gitignore` 등록 필수)
