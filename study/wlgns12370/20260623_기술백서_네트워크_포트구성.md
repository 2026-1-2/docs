# 프롬프트
> MMP 시스템의 네트워크 구성과 포트 역할을 정리해줘.

## 포트 접근 제어 정책

| 포트 | 접근 범위 | 용도 |
|---|---|---|
| 8002 | 외부 (Admin) | nginx 리버스 프록시 |
| 8554 | 내부망 (카메라) | MediaMTX RTSP 수신 |
| 8189 UDP/TCP | 내부망 | WebRTC ICE 미디어 전송 |
| 3306 | Docker 내부 | MySQL |
| 9997 | Docker 내부 | MediaMTX REST API |

---

## MediaMTX 스트리밍 포트

| 포트 | 프로토콜 | 용도 |
|---|---|---|
| 8889 | HTTP/WS | WebRTC 시그널링 |
| 8189/udp | UDP (SRTP) | ICE 미디어 전송 주경로 |
| 8189/tcp | TCP | ICE TCP Fallback |
| 8888 | HTTP | HLS 폴백 스트리밍 |

---

## 핵심 설정

- `PUBLIC_HOST` 설정 필수 → 브라우저가 접근하는 실제 IP/도메인 지정
- `mmp-net` 브리지 네트워크 → 서비스명으로 DNS 기반 통신
