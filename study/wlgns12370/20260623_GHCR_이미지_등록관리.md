# 프롬프트
> GHCR(GitHub Container Registry)을 이용한 Docker 이미지 관리 방법을 설명해줘.

## GHCR이란

GitHub에서 제공하는 컨테이너 이미지 레지스트리.  
GitHub 리포지토리와 통합되어 CI/CD에서 자동으로 이미지를 푸시/풀할 수 있다.

---

## MMP 이미지 구성

| 이미지 | 태그 | 설명 |
|---|---|---|
| `ghcr.io/2026-1-2/mmp-server` | `latest` | 백엔드 API 서버 |
| `ghcr.io/2026-1-2/client` | `latest` | React SPA + nginx |

---

## GHCR의 장점

- 소스코드 없이 이미지 pull만으로 동일 환경 재현
- GitHub Actions에서 `GITHUB_TOKEN`으로 자동 인증
- 이미지 태그로 버전 추적 → 롤백 용이

---

## 태그 전략

```
latest      → main 브랜치 최신 빌드
sha-abc1234 → 커밋 해시 기반 (롤백용)
```
