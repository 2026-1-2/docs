# 프롬프트
> MMP CI/CD 전체 자동화 흐름을 한눈에 정리해줘.

## 전체 파이프라인

```
개발자 로컬
    ↓ git push origin main
━━━━━━━━━━━━━━━━━━━━
CI 단계
├── 코드 체크아웃
├── 단위·통합 테스트
├── Docker 이미지 빌드
└── GHCR 푸시
━━━━━━━━━━━━━━━━━━━━
CD 단계
├── SSH로 MMP 서버 접속
├── docker compose pull
└── docker compose up -d
━━━━━━━━━━━━━━━━━━━━
MMP 운영 서버 (최신 버전 서비스 중)
```

---

## 개발자 입장

```bash
git add .
git commit -m "feat: 카메라 등록 UI 개선"
git push origin main
# → 이후 자동으로 운영 배포까지 완료
```

---

## 운영 담당자 입장

- 배포 현황: GitHub Actions 탭에서 실시간 확인
- 실패 시: GitHub에서 알림 수신
