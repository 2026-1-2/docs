# 프롬프트
> MMP 시스템을 다른 서버로 이전하는 절차를 설명해줘.

## GHCR 기반 이전의 장점

소스코드 없이 **이미지 + .env + 데이터**만으로 이전 완료.  
재빌드 불필요 → 이전 시간 최소화.

---

## 이전 절차

```bash
# 1. 신규 서버: Docker 설치
curl -fsSL https://get.docker.com | sh

# 2. 디렉터리 생성
sudo mkdir -p /hdd/mmp-data/{mysql,recordings}

# 3. 기존 서버에서 데이터 복사
docker compose stop mmp-mysql mmp-recorder
rsync -av /hdd/mmp-data/ new-server:/hdd/mmp-data/

# 4. .env 복사 및 PUBLIC_HOST 수정
scp .env new-server:/path/to/infra/.env

# 5. 신규 서버에서 실행 (GHCR에서 이미지 자동 pull)
docker compose up -d
```

---

## 예상 소요 시간

| 작업 | 시간 |
|---|---|
| Docker 설치 | ~5분 |
| 이미지 pull | ~2분 |
| 데이터 복사 | 용량에 따라 다름 |
| 전체 기동 | ~1분 |
