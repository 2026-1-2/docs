# 프롬프트
> mmp-net Docker 브리지 네트워크 구성이 왜 중요한지 설명해줘.

## mmp-net 설정

```yaml
networks:
  mmp-net:
    driver: bridge
```

모든 서비스가 `mmp-net`에 속함.

---

## 서비스명으로 DNS 통신

같은 네트워크 내 컨테이너는 **서비스명**으로 직접 통신:

```
mmp-api → mysql://mmp-mysql:3306/mmp
mmp-api → http://mmp-mediamtx:9997/v3/...
```

IP 주소 하드코딩 불필요.

---

## 격리 효과

- `mmp-net` 외부 컨테이너는 내부 서비스 접근 불가
- 외부에서는 nginx(:8002)를 통해서만 접근 가능
