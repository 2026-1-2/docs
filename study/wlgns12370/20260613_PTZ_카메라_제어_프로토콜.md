# 프롬프트
> PTZ 카메라란 무엇이고, ONVIF로 어떻게 제어하는지 설명해줘.

## PTZ란

**Pan-Tilt-Zoom** — 좌우(팬), 상하(틸트), 확대/축소(줌)가 가능한 카메라.

---

## ONVIF PTZ 제어

ONVIF 표준을 통해 HTTP SOAP 프로토콜로 카메라를 제어한다.

```
mmp-server
    ↓ ONVIF SOAP 요청
카메라 (192.168.0.100:8080)
    ↓
카메라 렌즈 이동 (Pan/Tilt/Zoom)
```

---

## PTZ 명령 종류

| 명령 | 설명 |
|---|---|
| ContinuousMove | 지정 속도로 계속 이동 |
| RelativeMove | 현재 위치에서 상대적 이동 |
| AbsoluteMove | 절대 좌표로 이동 |
| Stop | 이동 정지 |
| GotoPreset | 저장된 프리셋 위치로 이동 |
| SetPreset | 현재 위치를 프리셋으로 저장 |

---

## MMP REST API (프론트엔드 → mmp-server)

```
POST /api/cameras/{cameraId}/ptz
{
  "action": "move",
  "pan": 0.5,    # -1.0 ~ 1.0
  "tilt": 0.3,
  "zoom": 0.0
}
```

mmp-server가 ONVIF SOAP 요청으로 변환하여 카메라에 전달.
