# 프롬프트
> MMP 시스템 운영을 위한 서버 사양 요구사항을 정리해줘.

## 하드웨어 요구사항

| 항목 | 최소 사양 | 권장 사양 |
|---|---|---|
| OS | Docker 지원 Linux | Ubuntu 22.04 LTS |
| CPU | 4코어 | 8코어 이상 |
| RAM | 4 GB | 8 GB 이상 |
| OS 스토리지 | SSD 20 GB | SSD 50 GB |
| 녹화 스토리지 | HDD 500 GB | HDD 1 TB 이상 |
| 네트워크 | 100 Mbps | 1 Gbps |
| Docker | Engine 24.0+ | Compose Plugin v2 포함 |
