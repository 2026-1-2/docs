# 프롬프트
> MMP에서 .env 파일로 환경변수를 관리하는 방법과 보안 주의사항을 설명해줘.

## 주요 환경변수

```env
PUBLIC_HOST=192.168.0.100       # 브라우저가 접근하는 실제 서버 IP

DB_HOST=mmp-mysql
DB_PASSWORD=강력한비밀번호       # openssl rand -hex 32 권장

JWT_SECRET=강력한시크릿          # Access Token 서명 키
JWT_REFRESH_SECRET=별도시크릿   # Refresh Token 서명 키

INIT_ADMIN_USERNAME=admin
INIT_ADMIN_PASSWORD=초기비밀번호
```

---

## 보안 주의사항

1. `.env`는 반드시 `.gitignore`에 등록
2. `.env.example`만 git에 커밋 (실제 값 없이 키 목록만)
3. 시크릿 값 생성: `openssl rand -hex 32`

---

## 서버 이전 시

`.env` 파일을 `scp`로 신규 서버에 복사 → `PUBLIC_HOST` 수정 → 완료.
