# 프롬프트
> GitHub Actions에서 SSH로 원격 서버에 자동 배포하는 방법을 설명해줘.

## SSH 키 기반 인증 설정

```bash
# 로컬에서 SSH 키 생성
ssh-keygen -t ed25519 -C "deploy-key"

# 공개키를 서버에 등록
ssh-copy-id -i ~/.ssh/id_ed25519.pub ubuntu@192.168.0.100

# 개인키를 GitHub Secrets에 등록
# Settings → Secrets → SSH_PRIVATE_KEY
```

---

## GitHub Actions SSH 배포

```yaml
- name: 원격 배포
  uses: appleboy/ssh-action@v1
  with:
    host: ${{ secrets.SERVER_HOST }}
    username: ${{ secrets.SERVER_USER }}
    key: ${{ secrets.SSH_PRIVATE_KEY }}
    script: |
      cd /home/ubuntu/mmp-server/infra
      bash run.sh
```

---

## run.sh 스크립트

```bash
#!/bin/bash
set -e

echo "이미지 pull 중..."
docker compose pull

echo "서비스 재시작 중..."
docker compose up -d

echo "이전 이미지 정리..."
docker system prune -f

echo "배포 완료"
docker compose ps
```

---

## 보안 주의사항

- SSH 키는 배포 전용 키 별도 생성 (기존 개인 키 사용 금지)
- 서버에서 해당 키의 권한을 최소화 (`AllowedCommands` 설정 권장)
