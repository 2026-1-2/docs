# 프롬프트
> Docker 이미지 빌드 시 레이어를 최적화하는 방법을 설명해줘.

## Docker 레이어란

Dockerfile의 각 명령어(`RUN`, `COPY`, `ADD`)가 하나의 레이어를 생성.  
레이어는 캐시되어 변경된 레이어 이후만 재빌드.

---

## 레이어 캐시 활용

```dockerfile
# 나쁜 예: package.json이 바뀌지 않아도 항상 재설치
COPY . .
RUN npm install

# 좋은 예: package.json이 바뀔 때만 npm install 재실행
COPY package*.json ./
RUN npm install       # 이 레이어가 캐시됨
COPY . .              # 소스코드 변경 시 여기서부터 재빌드
```

---

## 멀티스테이지 빌드로 이미지 경량화

```dockerfile
FROM node:20 AS builder
RUN npm ci && npm run build

FROM nginx:alpine         # 최종 이미지는 nginx만
COPY --from=builder /app/dist /usr/share/nginx/html
# node_modules 포함 안 됨 → 이미지 크기 대폭 감소
```

---

## .dockerignore 설정

```
node_modules
.git
*.log
.env
dist
```

불필요한 파일이 이미지에 포함되지 않도록 제외.

---

## 이미지 크기 비교 예시

| 방식 | 이미지 크기 |
|---|---|
| node:20 (풀 이미지) | ~1.1 GB |
| node:20-alpine | ~170 MB |
| 멀티스테이지 + nginx:alpine | ~30 MB |
