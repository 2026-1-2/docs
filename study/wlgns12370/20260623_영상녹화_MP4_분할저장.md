# 프롬프트
> MMP의 영상 녹화 시스템을 설명해줘. 저장 방식, 볼륨 구성 포함해서.

## video-recorder 컨테이너

각 카메라의 RTSP 스트림을 구독하여 MP4로 저장.  
`config/camera/*.conf` 설정을 읽어 동작.

---

## 저장 방식

```
RTSP 스트림 → 1시간 단위 MP4 분할 저장
→ /hdd/mmp-data/recordings/cam1/2026-06-23_14-00.mp4
```

`video_interval_seconds: 3600` → 1시간마다 새 파일 생성.

---

## Docker 볼륨 구성

| 볼륨명 | 호스트 경로 | 용도 |
|---|---|---|
| recordings | `/hdd/mmp-data/recordings` | MP4 녹화 파일 (HDD) |
| mysql_data | `/hdd/mmp-data/mysql` | MySQL 데이터 (HDD) |
| recorder_logs | Docker 관리 볼륨 | 로그 파일 |
