# 프롬프트
> MMP에서 Docker 볼륨을 어떻게 구성했는지, HDD 마운트 이유도 포함해서 설명해줘.

## 볼륨 구성 전략

영상 녹화·DB 데이터는 **HDD에 직접 마운트**.  
이유: 대용량 영상을 SSD에 저장하면 비용 증가 + 수명 단축.

---

## 볼륨 종류

| 종류 | 볼륨명 | 경로 | 용도 |
|---|---|---|---|
| 호스트 마운트 | recordings | `/hdd/mmp-data/recordings` | MP4 녹화 파일 |
| 호스트 마운트 | mysql_data | `/hdd/mmp-data/mysql` | MySQL 데이터 |
| Docker 관리 | recorder_logs | (Docker 내부) | 로그 파일 |

---

## 사전 준비

```bash
sudo mkdir -p /hdd/mmp-data/mysql
sudo mkdir -p /hdd/mmp-data/recordings
```

---

## 서버 이전 시 데이터 마이그레이션

```bash
docker compose stop mmp-mysql mmp-recorder
rsync -av /hdd/mmp-data/ new-server:/hdd/mmp-data/
```
