# 프롬프트
> MediaMTX API의 내부 인증 설정을 설명해줘.

## 설정 개요

```yaml
authInternalUsers:
  - user: any
    permissions:
      - action: read
      - action: publish
```

`any` → 인증 없이 내부 네트워크에서 접근 허용.

---

## 왜 안전한가

MediaMTX API(:9997)는 `mmp-net` 브리지 네트워크에서만 접근 가능.

```
외부 인터넷 → 8002(nginx)만 접근 가능
MediaMTX :9997 → Docker 내부에서만 접근
```

---

## 설계 판단

현재 구성에서 외부 노출이 없으므로 `any` 허용이 실용적 선택.  
내부 서비스 간 인증 추가는 복잡도 대비 보안 이득이 크지 않음.
