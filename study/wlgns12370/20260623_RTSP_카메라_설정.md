# 프롬프트
> ONVIF를 지원하지 않는 RTSP 전용 카메라 설정 방법을 설명해줘.

## RTSP 카메라 설정 파일

`config/camera/*.conf` 파일로 관리.

```conf
camera {
    cam_name               cam1;
    cam_ip                 192.168.0.101;
    cam_port               554;
    cam_rtsp_path          Streaming/Channels/101;
    username               admin;
    password               CAMERA_PASSWORD;
    video_interval_seconds 3600;   # 1시간 단위 분할 녹화
    file_ext               '.mp4';
}
```

---

## 처리 흐름

```
config/camera/cam1.conf
    → video-recorder 컨테이너가 읽음
    → RTSP 스트림 접속
    → 1시간 단위 MP4로 HDD 저장
```

---

## ONVIF vs RTSP 비교

| 항목 | ONVIF | RTSP 전용 |
|---|---|---|
| PTZ 제어 | 가능 | 불가 |
| 스트리밍/녹화 | 가능 | 가능 |
| 설정 방법 | .env JSON | .conf 파일 |
