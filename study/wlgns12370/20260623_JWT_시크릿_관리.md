# 프롬프트
> JWT 시크릿 키를 안전하게 생성하고 관리하는 방법을 설명해줘.

## 안전한 시크릿 생성

```bash
openssl rand -hex 32
# 출력 예시: a3f8c2d1e5b7904f6c8a2d3e4f5b6c7d...
```

---

## 관리 원칙

```
DO:
  ✅ openssl rand -hex 32 로 생성
  ✅ .env 파일에 저장
  ✅ .gitignore에 .env 등록
  ✅ 환경별 다른 시크릿 사용

DON'T:
  ❌ "password123" 같은 추측 가능한 값
  ❌ git에 커밋
  ❌ 개발/운영 동일 시크릿 공유
```

---

## .env.example 패턴

```env
# .env.example (git에 커밋)
JWT_SECRET=your-jwt-secret-here
JWT_REFRESH_SECRET=your-refresh-secret-here

# .env (git 제외, 서버에만 존재)
JWT_SECRET=a3f8c2d1e5b7...
```
