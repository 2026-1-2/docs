# 프롬프트
> ONVIF PTZ 카메라 연동 방법을 설명해줘.

## ONVIF란

IP 카메라 표준 프로토콜. 제조사에 무관하게 동일 방식으로 제어 가능.

---

## MMP에서 ONVIF 카메라 등록

```env
ONVIF_CAMERAS=[
  {
    "cameraId": "cam-01",
    "hostname": "192.168.0.100",
    "port": 8080,
    "username": "admin",
    "password": "PASSWORD"
  }
]
```

---

## ONVIF로 가능한 기능

| 기능 | 설명 |
|---|---|
| PTZ 제어 | 팬·틸트·줌 원격 제어 |
| 프리셋 | 저장된 위치로 즉시 이동 |
| 이벤트 | 움직임 감지 알림 수신 |

---

## ONVIF 미지원 카메라

→ RTSP 전용으로 처리 (PTZ 불가, 스트리밍·녹화만 가능)
