# 프롬프트
> MMP에서 nginx가 리버스 프록시로 어떻게 동작하는지 설명해줘.

## 리버스 프록시란

클라이언트 요청을 받아 내부 서버로 전달하고, 응답을 다시 클라이언트에 돌려주는 중간 서버.  
MMP에서 nginx는 **단일 포트 8002**로 들어오는 모든 요청을 경로 기반으로 라우팅한다.

---

## nginx 라우팅 규칙

```nginx
server {
    listen 80;

    # React SPA
    location / {
        proxy_pass http://mmp-client;
    }

    # REST API
    location /api/ {
        proxy_pass http://mmp-api:3000;
    }

    # WebRTC 시그널링
    location /webrtc/ {
        proxy_pass http://mmp-mediamtx:8889;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

---

## 장점

- 외부에 단일 포트만 노출 → 방화벽 규칙 단순화
- SSL 인증서를 nginx 한 곳에서만 관리
- 내부 서비스 IP/포트 변경 시 nginx 설정만 수정
