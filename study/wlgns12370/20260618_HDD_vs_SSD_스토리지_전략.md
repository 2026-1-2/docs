# 프롬프트
> 영상 녹화 시스템에서 HDD와 SSD를 어떻게 나눠서 사용해야 하는지 설명해줘.

## MMP 스토리지 구성

```
SSD (OS + 서비스)
├── Ubuntu OS
├── Docker Engine
├── 컨테이너 레이어
└── mmp-server, nginx, mediamtx

HDD (데이터)
├── /hdd/mmp-data/recordings/  ← MP4 녹화 파일
└── /hdd/mmp-data/mysql/       ← MySQL 데이터
```

---

## HDD를 녹화에 쓰는 이유

| 항목 | SSD | HDD |
|---|---|---|
| 속도 | 빠름 | 느림 (순차 쓰기는 충분) |
| 용량 대비 가격 | 비쌈 | 저렴 |
| 내구성 (쓰기 수명) | TBW 한계 있음 | 쓰기 수명 걱정 적음 |
| 대용량 | 제한적 | 4TB~16TB 저렴하게 확보 가능 |

영상 녹화는 **대용량 순차 쓰기** → HDD 특성에 맞음.

## 카메라별 예상 저장 용량

```
해상도 1080p, H.264, 2 Mbps 기준
1시간당 약 900 MB
1일 24시간 = 약 21 GB/카메라

카메라 4대 × 30일 보관 = 약 2.5 TB
```

→ HDD 4TB 이상 권장.
