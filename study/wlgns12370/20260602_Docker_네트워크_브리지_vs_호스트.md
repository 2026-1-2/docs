# 프롬프트
> Docker 브리지 네트워크와 호스트 네트워크의 차이를 설명해줘. MMP는 왜 브리지를 선택했나?

## 브리지 네트워크 (MMP 선택)

```
호스트 OS
  └── Docker 브리지 (mmp-net)
        ├── mmp-api       (172.18.0.2)
        ├── mmp-mysql     (172.18.0.3)
        └── mmp-mediamtx  (172.18.0.4)
```

- 컨테이너끼리 가상 네트워크로 격리
- 서비스명으로 DNS 통신 가능 (`mmp-mysql:3306`)
- 외부에 노출할 포트만 명시적으로 publish

---

## 호스트 네트워크

```yaml
network_mode: "host"  # 호스트 IP/포트를 그대로 사용
```

- 컨테이너가 호스트 네트워크 스택을 직접 사용
- 격리 없음 → 포트 충돌 가능
- 성능은 약간 유리 (NAT 없음)

---

## MMP가 브리지를 선택한 이유

| 이유 | 설명 |
|---|---|
| 격리 | MySQL, MediaMTX API를 외부에서 직접 접근 불가 |
| 단일 포트 노출 | nginx(:8002)만 외부 노출 가능 |
| 서비스명 DNS | IP 하드코딩 없이 서비스명으로 통신 |
