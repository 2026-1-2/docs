# 프롬프트
> JWT 토큰의 구조를 설명해줘. Header, Payload, Signature 각각의 역할도 포함해서.

## JWT 구조

```
xxxxx.yyyyy.zzzzz
  │      │      │
Header Payload Signature
```

Base64URL로 인코딩된 세 부분을 `.`으로 연결.

---

## Header

```json
{
  "alg": "HS256",   // 서명 알고리즘
  "typ": "JWT"      // 토큰 타입
}
```

---

## Payload (Claims)

```json
{
  "sub": "user-123",          // 사용자 식별자
  "username": "admin",
  "role": "ADMIN",
  "iat": 1719100000,          // 발급 시각 (Unix timestamp)
  "exp": 1719100900           // 만료 시각 (15분 후)
}
```

⚠️ Payload는 암호화되지 않음 — Base64 디코딩으로 누구나 읽을 수 있음.  
민감 정보(비밀번호 등)를 Payload에 넣지 말 것.

---

## Signature

```
HMAC-SHA256(
  Base64(Header) + "." + Base64(Payload),
  JWT_SECRET
)
```

서버만 알고 있는 `JWT_SECRET`으로 서명 → 위조 여부 검증 가능.

---

## MMP에서의 검증 흐름

```
클라이언트 → Authorization: Bearer eyJ...
mmp-server → 서명 검증 (JWT_SECRET으로)
           → 만료 시각 확인
           → 사용자 정보 추출
```
