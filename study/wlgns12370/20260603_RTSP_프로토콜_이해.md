# 프롬프트
> RTSP 프로토콜이 무엇인지, IP 카메라에서 어떻게 사용되는지 설명해줘.

## RTSP란

**Real Time Streaming Protocol** — IP 카메라에서 영상 스트림을 전송하는 표준 프로토콜.  
HTTP와 유사하지만 미디어 제어(재생, 일시정지, 탐색)에 특화되어 있다.

---

## RTSP URL 형식

```
rtsp://[username]:[password]@[host]:[port]/[path]

예시:
rtsp://admin:password@192.168.0.101:554/Streaming/Channels/101
rtsp://admin:password@192.168.0.102:554/live
```

---

## 동작 방식

```
1. RTSP 연결 수립 (TCP :554)
2. DESCRIBE → 스트림 정보 요청
3. SETUP → 전송 방식 협상 (RTP/UDP 또는 RTP/TCP)
4. PLAY → 스트리밍 시작
5. RTP 패킷으로 실제 영상 데이터 전송
```

---

## MMP에서의 활용

- 카메라 → MediaMTX(:8554)로 RTSP 스트림 전송
- MediaMTX가 RTSP를 받아 WebRTC/HLS로 변환
- video-recorder가 RTSP를 직접 구독하여 MP4로 녹화
