# 프롬프트
> WebRTC와 HLS의 지연 차이를 비교 설명해줘. 영상관제 관점에서.

## 왜 지연이 중요한가

영상관제에서 지연은 **보안 사고 대응 시간**과 직결된다.  
5초 지연 = 침입자가 이미 5초 이동한 후에 화면에 보임.

---

## HLS vs WebRTC 비교

| 항목 | HLS (기존) | WebRTC (도입) |
|---|---|---|
| 전형적 지연 | 5 ~ 30 초 | 0.1 ~ 0.5 초 |
| 전송 프로토콜 | HTTP (TCP) | ICE / DTLS / SRTP (UDP) |
| 브라우저 지원 | hls.js 필요 | 네이티브 RTCPeerConnection |
| 폴백 | — | HLS 자동 폴백 지원 |

---

## HLS 지연의 원인

- 세그먼트 생성 시간 (보통 2~6초)
- 버퍼에 세그먼트가 쌓일 때까지 대기
- 구조적으로 수 초 이상의 지연 불가피

---

## MMP 폴백 전략

```
WebRTC 연결 성공 → 0.1~0.5초 지연
WebRTC 실패 (방화벽) → HLS 자동 폴백
```
