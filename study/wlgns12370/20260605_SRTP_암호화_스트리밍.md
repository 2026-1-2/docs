# 프롬프트
> WebRTC에서 SRTP가 무엇인지, 왜 보안 스트리밍에 필요한지 설명해줘.

## SRTP란

**Secure Real-time Transport Protocol** — RTP에 암호화·인증을 추가한 프로토콜.  
WebRTC는 SRTP를 의무적으로 사용한다 (W3C 표준).

---

## RTP vs SRTP

| 항목 | RTP | SRTP |
|---|---|---|
| 암호화 | 없음 | AES 암호화 |
| 인증 | 없음 | HMAC-SHA1 |
| 도청 가능 | 가능 | 불가 |
| WebRTC | 사용 불가 | 필수 |

---

## DTLS 핸드셰이크

SRTP 키 교환은 **DTLS(Datagram TLS)**로 이루어진다.

```
1. ICE 연결 수립 완료
2. DTLS 핸드셰이크 (인증서 교환, 키 협상)
3. SRTP 세션 키 도출
4. 이후 모든 미디어를 SRTP로 암호화 전송
```

---

## MMP에서의 적용

- MediaMTX가 DTLS/SRTP를 자동으로 처리
- `:8189/udp`로 암호화된 SRTP 패킷 전송
- 방화벽 환경에서는 `:8189/tcp`로 TCP 터널링
