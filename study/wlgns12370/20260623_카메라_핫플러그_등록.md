# 프롬프트
> MMP에서 카메라를 서버 재시작 없이 런타임에 추가/삭제하는 핫플러그 방식을 설명해줘.

## 기존 방식의 문제

설정 파일 수정 후 서버 재시작 필요 → 카메라 추가마다 서비스 중단 발생.

---

## MMP 핫플러그 구현

```
관리자 → React UI에서 카메라 추가
    → mmp-server → DB 저장
    → mmp-server → MediaMTX REST API 호출
    → 즉시 스트리밍 가능 (재시작 없음)
```

---

## sourceOnDemand 옵션

```json
{"sourceOnDemand": true}
```

클라이언트가 실제로 요청할 때만 RTSP 연결 수립.  
아무도 보지 않을 때 자동 해제 → 리소스 절약.
