# 프롬프트
> 온프레미스 방식과 클라우드 방식 영상관제 시스템을 비교해줘.

## 비교표

| 항목 | 온프레미스 (MMP) | 클라우드 기반 |
|---|---|---|
| 지연 | 내부망 → 매우 낮음 | 업로드 지연 발생 |
| 비용 | 초기 서버 비용 높음 | 월정액, 저장 용량당 과금 |
| 보안 | 내부망 완결, 외부 전송 없음 | 클라우드 업체 신뢰 필요 |
| 확장성 | 서버 추가 필요 | 즉시 확장 가능 |
| 인터넷 의존 | 불필요 | 필수 |
| 유지보수 | 직접 관리 | 클라우드 업체 지원 |

---

## MMP가 온프레미스를 선택한 이유

1. **보안 민감 환경** — 영상 데이터를 외부 클라우드에 전송하지 않음
2. **저지연 요구** — 내부망에서 0.1~0.5초 실현, 클라우드 업로드 지연 없음
3. **인터넷 불필요** — 내부망만으로 완전한 동작
4. **비용 예측 가능** — 트래픽·저장 용량 과금 없음

---

## 적합한 환경

| 환경 | 추천 방식 |
|---|---|
| 공장, 연구소, 금융기관 | 온프레미스 |
| 소규모 매장, 지점 | 클라우드 |
| 하이브리드 (본사+지점) | 온프레미스 + 클라우드 혼합 |
