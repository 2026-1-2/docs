# 프롬프트
> 기술백서.html을 보고서에 캡처해서 개조식으로 넣을 건데, 어떻게 하면 좋을지 알려줘.

## 브라우저 전체 페이지 캡처 (추천)

1. `기술백서.html`을 Chrome에서 열기
2. Chrome 확장 **GoFullPage** 또는 **FireShot** 사용 → 페이지 자동 분할 캡처
3. 또는 `Cmd+Shift+4` (macOS) → 영역 선택 스크린샷

---

## PDF 출력 후 이미지 추출

```
Chrome → 인쇄(Cmd+P) → 대상: PDF로 저장
```
- Preview에서 페이지별 캡처

---

## 캡처 팁

- `.page`가 794px 고정 너비 → 브라우저 줌 **100%**로 맞추고 캡처
- 6장 구현 결과 화면이 보고서에 가장 임팩트 있으니 필수 포함
- Word/HWP 삽입 시 이미지 너비를 단 너비에 맞추고 캡션 추가
