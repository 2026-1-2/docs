# 프롬프트
> MMP 시스템 전체 구성도와 데이터 흐름을 설명해줘.

## 전체 구성도

단일 VPC 내에서 Docker Compose로 운영. 외부에는 **단일 포트 8002**만 노출.

```
📹 Camera (RTSP)
      ↓
MediaMTX :8554  →  WebRTC :8889/:8189
      ↓
React Client (nginx :8002)
      ↓
관리자 브라우저
```

---

## 데이터 흐름

1. 카메라 → RTSP(:8554)로 MediaMTX에 스트림 전송
2. MediaMTX → WebRTC/HLS로 변환하여 클라이언트 제공
3. React 클라이언트 → nginx(:8002)를 통해 API 및 스트림 접근

---

## 설계 원칙

- 외부 노출 최소화 (단일 포트 8002)
- 내부망 완결 (TURN 서버 불필요)
- Docker Compose 단일 스택 운영
