# 프롬프트
> MMP 기술백서 1장 시스템 개요 내용을 정리해줘.

## MMP가 해결하는 문제

| 기존 문제 | MMP 해결 방식 |
|---|---|
| HLS 스트리밍 5~30초 지연 | WebRTC로 1초 미만으로 단축 |
| 벤더 종속적 하드웨어 의존 | ONVIF/RTSP 표준 기반 범용 카메라 지원 |
| 복잡한 설치/운영 | Docker Compose 단일 명령 배포 |
| 클라우드 외부 의존 | 내부망 완결 온프레미스 아키텍처 |

---

## 핵심 메시지

> WebRTC 기반 저지연 스트리밍 + 온프레미스 완결 구조로 기존 영상관제 솔루션의 한계를 극복한다.
