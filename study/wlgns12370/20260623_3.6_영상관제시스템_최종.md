## 3.6 MMP 온프레미스 영상관제 플랫폼 (최종본)

3.6.1 인프라 관리

· 기술 이전 및 서버 이전 용이성 확보를 위해 전체 서비스를 GHCR(GitHub Container Registry) 이미지로 등록·버전 관리
    - ghcr.io/2026-1-2/mmp-server:latest (백엔드 API 서버)
    - ghcr.io/2026-1-2/client:latest (React SPA + nginx)
    - 소스코드 없이 이미지 pull만으로 동일 환경 즉시 재현 → 서버 교체 시 다운타임 최소화
· GitHub Actions 기반 CI/CD 파이프라인으로 빌드·배포 전 과정 자동화
    - main 브랜치 push 시 자동 빌드·테스트 → GHCR 이미지 푸시 → SSH 원격 배포
    - 장애 발생 시 이전 이미지 태그로 docker compose up 재실행만으로 즉시 롤백
· docker compose up -d 단일 명령으로 5개 서비스 전체 스택 구동
· .env 환경변수 파일로 배포 환경 분리 → 서버 이전 시 파일 복사만으로 설정 완료

3.6.2 기술백서

· WebRTC 기반 저지연 실시간 스트리밍 채택
    - 기존 HLS 방식 대비 지연 6~30초 → 0.1~0.5초로 단축
    - WebRTC 연결 실패 시 HLS 자동 폴백 지원 → 다양한 네트워크 환경 대응
· ONVIF/RTSP 표준 프로토콜 채택으로 특정 벤더 종속 없이 기존 IP 카메라 그대로 연동
· 카메라 추가·삭제 시 MediaMTX REST API 호출로 재시작 없이 런타임 핫플러그 등록
· nginx 단일 포트(8002)만 외부 노출하는 최소 노출 원칙 적용
· 이중 토큰(Dual-Token) JWT 전략으로 세션 보안 강화
    - Access Token(단기) + Refresh Token(장기)을 별도 시크릿으로 분리 서명
· 영상 녹화는 1시간 단위 MP4 분할 저장, HDD 직접 마운트 볼륨으로 관리
