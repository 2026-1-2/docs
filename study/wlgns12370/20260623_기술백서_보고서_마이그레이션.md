# 프롬프트
> 기술백서 HTML 내용을 보고서 개조식으로 옮길 때 어떤 흐름으로 작업하면 좋을지 설명해줘.

## 전체 작업 흐름

```
1. 기술백서.html 브라우저에서 열기
2. 섹션별 캡처 (GoFullPage 또는 Cmd+Shift+4)
3. 핵심 내용 개조식으로 정리
4. 이미지 + 개조식 텍스트 보고서에 삽입
5. 캡션 추가 및 레이아웃 조정
```

---

## 변환 방법

### 표 → 개조식

```
기술백서 표:
HLS | 5~30초 | HTTP
WebRTC | 0.1~0.5초 | UDP

개조식:
· WebRTC 기반 저지연 스트리밍 채택
  - HLS 대비 5~30초 → 0.1~0.5초로 단축
```

### 본문 → 개조식

```
기술백서: "서버 재시작 없이 런타임에 카메라를 핫플러그 방식으로 관리..."

개조식: · MediaMTX REST API 호출로 재시작 없이 런타임 핫플러그 등록
```

---

## 핵심 원칙

- 배경 설명은 생략, **수치·결과 중심**으로 정리
- 이미지가 설명을 대신할 수 있으면 텍스트 압축
