## Question)
```
이 문서에, 기본 비밀번호와 관련된 내용이 있나?
```
## Answer)
제공해주신 사용자 매뉴얼 내용을 검토한 결과, 이 문서에는 기기의 **기본 비밀번호(Default Password)와 관련된 내용이 없습니다.**[cite: 1]

대신, 매뉴얼은 보안을 위해 사용자가 기기를 처음 사용할 때 직접 비밀번호를 설정하여 **활성화(Activation)**해야 한다고 명시하고 있습니다.[cite: 1] 주요 내용은 다음과 같습니다.

*   **기기 활성화 필수**: 네트워크를 통해 기기에 처음 접근할 때, 사용자 계정과 데이터 보안을 위해 반드시 로그인 비밀번호를 설정해야 합니다.[cite: 1]
*   **활성화 방법**:
    *   **SADP 도구 사용**: 온라인 장치를 검색한 후 'admin' 계정의 새 비밀번호를 입력하여 활성화합니다.[cite: 1]
    *   **iVMS-4200 소프트웨어 사용**: 비활성 상태의 카메라를 선택하고 관리자 비밀번호를 생성하여 활성화합니다.[cite: 1]
    *   **웹 브라우저 사용**: 기기의 기본 IP 주소($192.168.1.64$)로 접속하여 관리자 비밀번호를 생성하고 확인하는 과정을 거칩니다.[cite: 1]
*   **강력한 비밀번호 권장**: 보안 강화를 위해 최소 8자 이상의 대문자, 소문자, 숫자 및 특수문자를 포함한 비밀번호를 생성할 것을 강력히 권고하고 있습니다.[cite: 1]

따라서 별도의 초기 비밀번호를 찾는 대신, 위의 활성화 절차에 따라 직접 비밀번호를 설정하여 사용하셔야 합니다.[cite: 1]

## Question)
```
처음 SADP 프로그램에 감지가 되면 Inactive 라고 뜨는 것 같은데, 나의 경우에는 처음부터 Activate 가 되어 있네

왜 그런거지? 찾아보고 알려주기 바람.
```
## Answer)
기기 상태가 **Inactive(비활성)**가 아닌 **Active(활성)**로 나타난다는 것은, 이미 누군가에 의해 **로그인 비밀번호가 설정되었다**는 것을 의미합니다. 신제품이라면 비활성 상태인 것이 정상이지만, 다음과 같은 몇 가지 이유로 이미 활성화되어 있을 수 있습니다.

### 1. 판매처 또는 대리점의 사전 세팅
가장 흔한 경우입니다. 판매처에서 제품의 불량 여부를 테스트하거나, 사용자의 편의를 위해 **임의의 비밀번호(예: `admin12345`, `12345678a` 등)**로 미리 활성화하여 보내주는 경우가 있습니다. 특히 특정 IP 대역으로 맞춰서 보내달라고 요청했거나, 패키지 상품인 경우 이런 작업이 미리 진행되기도 합니다.

### 2. 반품 또는 전시 제품 (리퍼비시)
단순 변심으로 반품된 제품이나 매장에 전시되었던 제품이 재포장되어 유통되었을 가능성이 있습니다. 이전 사용자가 설치 과정에서 비밀번호를 설정했다면 SADP에서 'Active'로 표시됩니다.

### 3. 동일 네트워크 내 타인의 활성화
SADP는 동일한 로컬 네트워크(LAN)에 있는 모든 장치를 검색합니다. 만약 사무실이나 공용 네트워크에서 작업 중이라면, **다른 관리자나 동료가 먼저 기기를 발견하고 활성화**했을 수 있습니다.

### 4. OEM 또는 특정 브랜드 전용 모델
일부 하이킹비전 OEM 제품이나 특정 보안 업체 전용 모델은 공장에서 출고될 때부터 **초기 비밀번호가 지정된 상태**로 나오기도 합니다. 이 경우 매뉴얼에 별도의 'Default Password'가 기재되어 있는지 확인이 필요합니다.

## **해결 방법: 비밀번호를 모른다면?**

비밀번호를 직접 설정한 적이 없는데 활성화되어 있다면, 보안을 위해 **초기화**를 진행하는 것이 좋습니다.

*   **하드웨어 리셋**: 카메라 본체의 Reset 버튼을 기기가 켜진 상태에서 10~15초간 길게 누르면 공장 초기화가 진행되며 다시 **Inactive** 상태로 돌아갑니다.
*   **비밀번호 찾기(Forgot Password)**: SADP 프로그램의 'Forgot Password' 기능을 클릭하여 판매처나 제조사에 XML 파일을 보내 리셋 코드를 받을 수 있습니다. (다만, 직접 초기화 버튼을 누르는 것이 가장 빠릅니다.)

혹시 이 제품을 구매하실 때 판매처로부터 별도의 비밀번호 안내를 받으신 적이 있나요?

## Question)
```
하드웨어 리셋은 어떻게 하지? 따로 버튼은 없는 것 같은데. 버튼 위치를 찾아보고 알려주기 바람.
모델명은 DS-2DE2C400MWG-E
```
## Answer)
사용 중인 **DS-2DE2C400MWG-E** 모델은 렌즈가 움직이는 PT(Pan/Tilt)형 카메라이기 때문에, 리셋 버튼이 외부로 드러나 있지 않고 보호 커버 안쪽에 숨겨져 있습니다.

### **1. 리셋 버튼 및 SD 카드 슬롯 위치**
이 모델의 리셋 버튼은 **카메라 렌즈(구체 부분)의 아랫면**에 숨겨져 있습니다. 다음 순서대로 확인해 보세요.

1.  **렌즈를 수동으로 위로 끝까지 올리기**: 전원을 끈 상태나 조심스러운 상태에서 카메라의 '눈' 부분(렌즈)을 손으로 천천히 위쪽 방향으로 끝까지 밀어 올립니다.
2.  **보호 커버 확인**: 렌즈를 위로 올리면 가려져 있던 아래쪽에 **작은 플라스틱 덮개와 나사(보통 1~2개)**가 보입니다.
3.  **커버 열기**: 정밀 드라이버를 사용해 나사를 풀고 커버를 열면, 안쪽에 **MicroSD 카드 슬롯**과 그 바로 옆에 아주 작은 **리셋(Reset) 버튼**이 위치해 있습니다.

### **2. 하드웨어 리셋 방법 (공장 초기화)**
버튼을 찾으셨다면 다음 절차를 따라야 확실하게 초기화됩니다.

*   **진행 순서**:
    1.  카메라에 **전원을 연결**한 상태여야 합니다.
    2.  리셋 버튼을 **약 10~15초 동안 길게** 꾹 누릅니다.
    3.  버튼을 누르고 있는 동안 카메라에서 '띠링' 소리가 나거나, LED 조명이 깜빡이는 등의 반응이 오면 버튼에서 손을 뗍니다.
    4.  약 1~2분 정도 기다리면 카메라가 재부팅됩니다.

---

**초기화 결과 확인**:
재부팅이 완료된 후 PC에서 **SADP 프로그램**을 다시 실행해 보세요. 정상적으로 초기화되었다면 상태가 **'Active'에서 'Inactive'**로 변경되어 있을 것입니다. 이제 원하시는 비밀번호를 새로 설정하여 활성화하시면 됩니다.

## Question)
```
DS-2SE3C204MWG-E/12
이건 어디에 있지?
```
## Answer)
문의하신 **DS-2SE3C204MWG-E/12** 모델은 하단에 고정 렌즈(Bullet)와 상단에 회전 렌즈(PTZ)가 함께 있는 **TandemVu** 제품입니다.

이 모델의 리셋 버튼은 이전 안내드린 일반 PTZ 카메라와 마찬가지로 **회전하는 구체(PTZ 헤드) 부분**에 숨겨져 있습니다.

### **리셋 버튼 및 SD 카드 슬롯 위치**
1.  **PTZ 헤드 회전**: 카메라의 전원을 끈 상태에서, 회전하는 구체(렌즈 부분)를 수동으로 위쪽이나 아래쪽으로 천천히 끝까지 돌려보세요. 
2.  **보호 커버 확인**: 구체 표면에 **나사 2개**로 고정된 작은 직사각형 모양의 플라스틱 덮개가 보일 것입니다.
3.  **커버 개방**: 나사를 풀고 덮개를 열면 그 안에 **MicroSD 카드 슬롯**과 **리셋(Reset) 버튼**이 나란히 배치되어 있습니다.



### **리셋 방법**
1.  카메라에 **전원이 공급되고 있는 상태**여야 합니다.
2.  리셋 버튼을 **약 10~15초 동안** 길게 꾹 누릅니다.
3.  카메라가 재부팅되는 소리가 나거나 LED가 반응하면 버튼에서 손을 뗍니다.
4.  재부팅 후 **SADP 프로그램**에서 다시 검색하면 상태가 **Inactive(비활성)**로 돌아가 있을 것입니다.

**주의사항**: TandemVu 모델은 고정 렌즈와 회전 렌즈가 결합된 구조이므로, 덮개를 열 때 나사가 떨어지지 않도록 주의하시기 바랍니다. 덮개를 연 후에는 방수를 위해 반드시 다시 단단히 조여주어야 합니다.

## Question)
```
DS-2DE2C400MWG-E 와 같은 위치에 있다는 것인가? 없는데.
위치를 찾아보고 알려주기 바람.
```
## Answer)
**DS-2SE3C204MWG-E/12** 모델은 이전 모델(DS-2DE2C400MWG-E)과는 기기 설계 구조가 달라 리셋 버튼의 위치도 다릅니다. 이 모델은 고정 렌즈와 회전 렌즈가 결합된 **TandemVu 스피드 돔** 제품으로, 버튼이 더 깊숙이 보호되어 있습니다.

### **1. 리셋 버튼 및 SD 카드 슬롯 위치**
이 모델의 리셋 버튼은 렌즈 아래가 아니라, **회전하는 구체(PTZ 헤드)의 측면이나 뒤쪽**에 있는 별도의 **액세스 커버** 안에 숨겨져 있습니다.

*   **위치**: 회전하는 구체 부분(검은색 렌즈가 있는 뭉치)을 살펴보면, 렌즈 정면이 아닌 **옆면이나 뒷면**에 나사 2개로 고정된 작은 직사각형 모양의 덮개가 있습니다.
*   **찾는 법**: 
    1.  카메라의 전원을 끄고, 회전하는 머리 부분을 손으로 좌우로 천천히 돌려가며 측면/후면에 **나사로 고정된 작은 판**이 있는지 확인하세요.
    2.  나사를 풀고 덮개를 열면 그 안에 **MicroSD 카드 슬롯**과 바로 옆에 **리셋(Reset) 버튼**이 있습니다.



---

### **2. 하드웨어 리셋 방법 (중요)**
버튼을 찾으신 후 초기화를 진행할 때, 단순히 누르는 것이 아니라 아래의 '전원 연동' 절차를 따라야 정확히 공장 초기화가 됩니다.

1.  **전원 차단**: 카메라에 연결된 전원 케이블(또는 PoE 랜선)을 뽑습니다.
2.  **버튼 누르기**: 리셋 버튼을 누른 상태를 **유지**합니다.
3.  **전원 연결**: 버튼을 누른 채로 전원 케이블(또는 PoE 랜선)을 다시 꽂습니다.
4.  **대기**: 버튼을 떼지 말고 **약 15~20초 동안** 계속 누르고 있습니다.
5.  **완료**: 버튼에서 손을 떼고 약 2~3분간 기다리면 카메라가 스스로 재부팅되며 초기화됩니다.

### **3. 결과 확인**
재부팅이 끝나면 **SADP 프로그램**을 새로고침해 보세요. 상태(Status)가 **'Inactive'**로 바뀌었다면 성공입니다.

**팁**: 만약 구체(머리) 부분에 덮개가 전혀 보이지 않는다면, 드물게 **고정된 몸체(Bullet 채널 위쪽)** 부분에 덮개가 있는 경우도 있으니 몸체 주변의 나사 덮개를 확인해 보시기 바랍니다. 하지만 대부분의 3인치 TandemVu 모델은 PTZ 구체 측면에 위치합니다.

ONVIF 테스트를 위해서는 단순히 브라우저에 주소를 입력하는 방식이 아니라, 장치의 **서비스 엔드포인트(Service Endpoint)** 주소로 규격화된 **SOAP(XML) 메시지**를 보내야 합니다.

가장 먼저 확인해야 할 URL 구조와 테스트 시 주의사항을 정리해 드립니다.

-----

### 1\. ONVIF 서비스 URL 기본 구조

가장 먼저 통신을 시작하는 '장치 관리(Device Management)' 서비스의 URL은 보통 다음과 같습니다.

  * **구조:** `http://[IP주소]:[ONVIF포트]/onvif/device_service`
  * **예시:** `[http://192.168.1.64:80/onvif/device_service](http://192.168.1.64:80/onvif/device_service)`
      * \*하이킹비전(Hikvision) 등 대부분의 제조사는 기본 포트로 **80** 또는 \*\*8000**, **8081** 등을 사용합니다.*



---

### 2. 하이킹비전 카메라 필수 사전 설정
하이킹비전 기기는 보안을 위해 **ONVIF가 기본적으로 비활성화**되어 있거나, 일반 계정과는 별도의 **ONVIF 전용 계정**을 만들어야 통신이 가능합니다.

1.  **웹 설정 접속**: `Configuration` → `Network` → `Advanced Settings` → `Integration Protocol`로 이동합니다.
2.  **ONVIF 활성화**: `Enable Open Network Video Interface`를 체크합니다.
3.  **사용자 추가(Add)**: 반드시 여기서 사용자를 추가해야 합니다. (이때 만든 ID/PW가 테스트용 인증 정보가 됩니다.)
4.  **저장**: `Save`를 눌러 설정을 반영합니다.

---

### 3. 테스트 방법 (툴 사용 권장)
URL만으로는 결과를 확인하기 어렵기 때문에, 보통 다음 도구들을 사용하여 테스트를 진행합니다.

#### A. ONVIF Device Manager (무료 오픈소스) - **가장 추천**
가장 대중적인 테스트 툴입니다. 
1.  프로그램 왼쪽 하단 `Add`를 누르고 `http://[IP]:[Port]/onvif/device_service`를 입력합니다.
2.  상단 `Login` 버튼을 눌러 위에서 만든 ONVIF 계정 정보를 입력합니다.
3.  장치가 인식되면 `Identification`, `Video streaming`, `PTZ` 등 모든 기능을 클릭 한 번으로 테스트할 수 있습니다.

#### B. Postman 또는 cURL (개발자용)
직접 XML 요청을 보내고 싶다면 `GetSystemDateAndTime` 같은 간단한 명령어를 POST 방식으로 보냅니다.
*   **Method**: `POST`
*   **Header**: `Content-Type: application/soap+xml; charset=utf-8`
*   **Body**: ONVIF 규격 XML 본문

---

### 4. 참고: RTSP 스트리밍 URL (ONVIF를 통해 얻는 결과)
ONVIF 테스트의 최종 목적이 영상 주소를 얻는 것이라면, ONVIF가 내부적으로 반환해주는 RTSP 주소는 대략 다음과 같은 형식을 띱니다.

> `rtsp://[ID]:[PW]@[IP]:554/Streaming/Channels/101`

**질문하신 의도가 개발 중인 프로그램에서 특정 기능을 호출하려는 것인가요?** 그렇다면 어떤 기능(영상 보기, PTZ 제어 등)을 테스트하고 싶은지 알려주시면 해당 XML 예시를 드릴 수 있습니다.
