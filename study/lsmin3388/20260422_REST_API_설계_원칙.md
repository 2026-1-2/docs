## 1. 개요

버티포트 CCTV 감시 시스템의 백엔드는 NestJS 기반 REST API로 구축한다. 카메라 관리, 스트림 제어, 로그, 인증, 시스템 설정 도메인을 일관된 규칙으로 설계한다.

## 2. REST 아키텍처 제약 조건

| 제약 조건 | 설명 | 프로젝트 적용 |
|---|---|---|
| **Client-Server** | 관심사 분리 | React / NestJS 분리 |
| **Stateless** | 요청 독립적 | JWT 토큰 기반 인증 |
| **Cacheable** | 캐시 여부 명시 | Cache-Control 헤더 |
| **Uniform Interface** | 일관된 인터페이스 | URL/메서드/응답 통일 |
| **Layered System** | 중간 계층 허용 | Nginx 리버스 프록시 |

## 3. HTTP 메서드와 상태 코드

| 메서드 | 용도 | 멱등성 | 응답 코드 |
|---|---|---|---|
| `GET` | 리소스 조회 | O | 200 OK |
| `POST` | 리소스 생성 | X | 201 Created |
| `PATCH` | 부분 수정 | X | 200 OK |
| `DELETE` | 리소스 삭제 | O | 204 No Content |

| 에러 코드 | 의미 | 사용 상황 |
|---|---|---|
| `400` | Bad Request | 유효성 검증 실패 |
| `401` | Unauthorized | JWT 없음/만료 |
| `403` | Forbidden | 관리자 전용 API |
| `404` | Not Found | 존재하지 않는 리소스 |
| `409` | Conflict | 중복 IP 등록 |
| `429` | Too Many Requests | Rate Limiting |

## 5. 페이지네이션과 필터링

```text
GET /api/v1/cameras?page=1&limit=20&sort=name&order=asc&status=ACTIVE
```

```typescript
async findAll(query: CameraQueryDto): Promise<PaginatedResponse<Camera>> {
  const { page = 1, limit = 20, sort = 'createdAt', order = 'desc', status, search } = query;
  const where: Prisma.CameraWhereInput = {
    ...(status && { status }),
    ...(search && { OR: [{ name: { contains: search } }, { ipAddress: { contains: search } }] }),
  };
  const [items, total] = await Promise.all([
    this.prisma.camera.findMany({ where, skip: (page - 1) * limit, take: limit, orderBy: { [sort]: order } }),
    this.prisma.camera.count({ where }),
  ]);
  return { items, total, page, limit, totalPages: Math.ceil(total / limit) };
}
```

## 8. NestJS 컨트롤러 구현 예시

```typescript
@ApiTags("Cameras")
@ApiBearerAuth()
@UseGuards(JwtAuthGuard)
@Controller("api/v1/cameras")
export class CamerasController {
  constructor(private readonly camerasService: CamerasService) {}

  @Get()
  findAll(@Query() query: CameraQueryDto) { return this.camerasService.findAll(query); }

  @Post()
  @UseGuards(RolesGuard) @Roles("admin")
  @HttpCode(HttpStatus.CREATED)
  create(@Body() dto: CreateCameraDto) { return this.camerasService.create(dto); }

  @Patch(":id")
  @UseGuards(RolesGuard) @Roles("admin")
  update(@Param("id", ParseIntPipe) id: number, @Body() dto: UpdateCameraDto) {
    return this.camerasService.update(id, dto);
  }

  @Delete(":id")
  @UseGuards(RolesGuard) @Roles("admin")
  @HttpCode(HttpStatus.NO_CONTENT)
  remove(@Param("id", ParseIntPipe) id: number) { return this.camerasService.remove(id); }
}
```
