# ONVIF PTZ 카메라 제어 프로토콜

## 1. ONVIF란?

ONVIF(Open Network Video Interface Forum)는 IP 기반 보안 장치 간 표준 통신 프로토콜이다.
제조사에 관계없이 카메라, NVR, 소프트웨어 간 호환성을 보장한다.

---

## 2. ONVIF 프로필

| 프로필 | 용도 |
|--------|------|
| Profile S | 영상 스트리밍 (RTSP) |
| Profile G | 영상 녹화 및 검색 |
| Profile T | 고급 영상 스트리밍 (H.265, 이벤트) |
| Profile C | 출입 통제 |

Hikvision 카메라는 주로 Profile S, T를 지원하며, PTZ 제어는 Profile S에 포함된다.

---

## 3. PTZ(Pan/Tilt/Zoom) 제어

### 3-1. PTZ 동작 종류

| 동작 | 설명 | ONVIF 메서드 |
|------|------|-------------|
| Pan | 좌우 회전 | ContinuousMove |
| Tilt | 상하 회전 | ContinuousMove |
| Zoom | 확대/축소 | ContinuousMove |
| Preset | 사전 설정 위치로 이동 | GotoPreset |
| Stop | 움직임 중지 | Stop |
| Home | 홈 포지션으로 복귀 | GotoHomePosition |

### 3-2. ContinuousMove

카메라를 지정된 속도로 계속 움직인다. Stop 명령이 올 때까지 동작을 유지한다.

```
속도 범위: -1.0 ~ 1.0

Pan:  -1.0 (왼쪽) ← 0 (정지) → 1.0 (오른쪽)
Tilt: -1.0 (아래) ← 0 (정지) → 1.0 (위)
Zoom: -1.0 (축소) ← 0 (정지) → 1.0 (확대)
```

## 4. ONVIF SOAP 통신

ONVIF는 SOAP(XML) 기반으로 통신한다.

### 4-1. ContinuousMove 요청

```xml
<?xml version="1.0" encoding="UTF-8"?>
<s:Envelope xmlns:s="http://www.w3.org/2003/05/soap-envelope"
            xmlns:tptz="http://www.onvif.org/ver20/ptz/wsdl">
  <s:Body>
    <tptz:ContinuousMove>
      <tptz:ProfileToken>profile_1</tptz:ProfileToken>
      <tptz:Velocity>
        <PanTilt x="0.5" y="0.0"/>
        <Zoom x="0.0"/>
      </tptz:Velocity>
    </tptz:ContinuousMove>
  </s:Body>
</s:Envelope>
```

### 4-2. Stop 요청

```xml
<tptz:Stop>
  <tptz:ProfileToken>profile_1</tptz:ProfileToken>
  <tptz:PanTilt>true</tptz:PanTilt>
  <tptz:Zoom>true</tptz:Zoom>
</tptz:Stop>
```

## 5. 프로젝트 구현

### 5-1. Node.js ONVIF 라이브러리

```bash
npm install onvif
```

### 5-2. PTZ 제어 서비스

```typescript
import { Cam } from 'onvif';

async function connectCamera(ip: string, user: string, password: string) {
  return new Promise<Cam>((resolve, reject) => {
    const cam = new Cam({
      hostname: ip,
      username: user,
      password: password,
      port: 80,
    }, (err) => {
      if (err) reject(err);
      else resolve(cam);
    });
  });
}

async function continuousMove(cam: Cam, x: number, y: number, zoom: number) {
  return new Promise<void>((resolve, reject) => {
    cam.continuousMove({
      x, y, zoom,
      timeout: 1,
    }, (err) => {
      if (err) reject(err);
      else resolve();
    });
  });
}

async function stopMove(cam: Cam) {
  return new Promise<void>((resolve, reject) => {
    cam.stop({}, (err) => {
      if (err) reject(err);
      else resolve();
    });
  });
}
```

### 5-3. REST API 설계

```
POST /cameras/:id/ptz/move     { x: 0.5, y: 0, zoom: 0 }
POST /cameras/:id/ptz/stop
POST /cameras/:id/ptz/preset   { presetId: 1 }
POST /cameras/:id/ptz/home
GET  /cameras/:id/ptz/presets   프리셋 목록 조회
```

### 5-4. 프론트엔드 PTZ UI

```
         [↑]
    [←] [Stop] [→]     [+] Zoom In
         [↓]            [-] Zoom Out

    [Preset 1] [Preset 2] [Preset 3] [Home]
```

버튼 Press 시 `move` API 호출, Release 시 `stop` API 호출하여
ContinuousMove 동작을 제어한다.

## 6. Hikvision ISAPI를 통한 PTZ 제어 (대안)

ONVIF 외에 Hikvision 독자 API인 ISAPI로도 PTZ를 제어할 수 있다.

```
PUT http://[카메라IP]/ISAPI/PTZCtrl/channels/1/continuous
Content-Type: application/xml
Authorization: Digest ...

<PTZData>
  <pan>50</pan>
  <tilt>0</tilt>
  <zoom>0</zoom>
</PTZData>
```

ISAPI는 ONVIF보다 응답 속도가 빠르고, Hikvision 전용 기능(SmartEvent 등)에 접근할 수 있다는 장점이 있다. 단, 다른 제조사 카메라와의 호환성은 없다.

---

## 7. 프로젝트 선택: ONVIF vs ISAPI

| 항목 | ONVIF | ISAPI |
|------|-------|-------|
| 호환성 | 모든 제조사 | Hikvision 전용 |
| 응답 속도 | 보통 | 빠름 |
| 기능 범위 | 표준 범위 | 전체 기능 접근 |
| 인증 | WS-Security | Digest Auth |

현재 프로젝트에서는 Hikvision 카메라만 사용하므로 ISAPI를 우선 적용하되,
향후 다른 제조사 카메라 지원을 위해 ONVIF 인터페이스도 준비해 두는 것이 좋다.
