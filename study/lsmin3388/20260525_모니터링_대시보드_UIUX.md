# CCTV 모니터링 대시보드 UI/UX 설계

## 1. CCTV 관제 시스템 UI 레퍼런스 분석

기존 상용 관제 시스템의 UI 패턴을 분석하여 공통 설계 원칙을 도출한다.

| 시스템 | 특징 | 참고 사항 |
|--------|------|----------|
| Hikvision iVMS-4200 | 다크 테마, 멀티 그리드, 트리 구조 카메라 목록 | 기능은 풍부하지만 UI 복잡도 높음 |
| Milestone XProtect | 깔끔한 레이아웃, 타임라인 중심 | 직관적 타임라인 UI |
| Nx Witness (Network Optix) | 모던 UI, 드래그앤드롭 레이아웃 | 웹 기반, 반응형 설계 |
| Shinobi (오픈소스) | 웹 기반, 경량 대시보드 | 기능 제한적이지만 빠른 로딩 |

### 공통 UI 패턴

- 어두운 배경: 장시간 모니터링 시 눈의 피로 감소
- 멀티 그리드 뷰: 다수 카메라를 한 화면에 배치
- 사이드바 카메라 트리: 카메라를 그룹/위치별로 계층 구조 탐색
- 하단 타임라인: 시간축 기반 녹화 영상 탐색
- 실시간 상태 표시: 카메라 온/오프라인, 녹화 상태 아이콘

### 2-2. 설계 원칙

| 원칙 | 설명 |
|------|------|
| 정보 밀도 최적화 | 한 화면에 필요한 정보를 모두 표시하되 과밀하지 않게 |

| 키보드 단축키 | 풀스크린, 그리드 전환 등 빠른 조작 지원 |

## 3. 다크 테마 디자인 (관제 센터 환경)

관제 센터는 조명이 낮은 환경에서 장시간 모니터를 주시하므로 다크 테마가 필수이다.

### 3-1. 컬러 팔레트

```css
:root {
  /* 배경 */
  --bg-primary: #0a0e17;      /* 최상위 배경 */
  --bg-secondary: #111827;     /* 카드/패널 배경 */
  --bg-tertiary: #1f2937;      /* 호버/활성 상태 */

  /* 텍스트 */
  --text-primary: #e5e7eb;     /* 기본 텍스트 */
  --text-secondary: #9ca3af;   /* 보조 텍스트 */
  --text-muted: #6b7280;       /* 비활성 텍스트 */

  /* 상태 색상 */
  --status-online: #22c55e;    /* 온라인 (녹색) */
  --status-offline: #ef4444;   /* 오프라인 (빨간색) */
  --status-recording: #3b82f6; /* 녹화중 (파란색) */
  --status-warning: #f59e0b;   /* 경고 (노란색) */

  /* 강조 */
  --accent-primary: #3b82f6;   /* 주요 강조색 */
  --border-color: #374151;     /* 테두리 */
}
```

### 3-2. 다크 테마 적용 원칙

- 순수 검정(#000)은 피하고 짙은 남색 계열 사용 (눈의 피로 감소)
- 텍스트 대비율 WCAG AA 기준(4.5:1) 이상 유지
- 상태 색상은 색각 이상 사용자도 구분 가능하도록 아이콘/텍스트 보조

## 4. 카메라 그리드 레이아웃 (1x1, 2x2, 3x3)

### 4-1. 그리드 모드 정의

| 모드 | 행 x 열 | 동시 표시 카메라 | 단축키 |
|------|---------|----------------|--------|
| 단일 | 1 x 1 | 1대 | `1` |
| 2x2 | 2 x 2 | 4대 | `2` |
| 3x3 | 3 x 3 | 9대 | `3` |
| 4x4 | 4 x 4 | 16대 | `4` |

### 4-2. React 그리드 컴포넌트

```tsx
import React, { useState } from 'react';

type GridMode = '1x1' | '2x2' | '3x3' | '4x4';

interface CameraGridProps {
  cameras: Camera[];
}

const gridConfig: Record<GridMode, number> = {
  '1x1': 1,
  '2x2': 2,
  '3x3': 3,
  '4x4': 4,
};

const CameraGrid: React.FC<CameraGridProps> = ({ cameras }) => {
  const [mode, setMode] = useState<GridMode>('2x2');
  const cols = gridConfig[mode];

  return (
    <div>
      <div className="grid-controls">
        {Object.keys(gridConfig).map((m) => (
          <button
            key={m}
            className={mode === m ? 'active' : ''}
            onClick={() => setMode(m as GridMode)}
          >
            {m}
          </button>
        ))}
      </div>
      <div
        className="camera-grid"
        style={{
          display: 'grid',
          gridTemplateColumns: `repeat(${cols}, 1fr)`,
          gap: '4px',
        }}
      >
        {cameras.slice(0, cols * cols).map((cam) => (
          <CameraCell key={cam.id} camera={cam} />
        ))}
      </div>
    </div>
  );
};
```

### 4-3. 더블클릭 확대

그리드 내 카메라 셀을 더블클릭하면 해당 카메라가 1x1 풀스크린으로 전환된다.
다시 더블클릭하거나 ESC 키로 이전 그리드 모드로 복귀한다.

## 5. 실시간 상태 표시 (온라인/오프라인/녹화중)

### 5-1. 카메라 상태 정의

```typescript
enum CameraStatus {
  ONLINE = 'online',       // 연결됨, 스트리밍 정상
  OFFLINE = 'offline',     // 연결 끊김
  RECORDING = 'recording', // 녹화 진행 중
  ERROR = 'error',         // 스트림 오류
}
```

### 5-2. 상태 배지 컴포넌트

```tsx
const StatusBadge: React.FC<{ status: CameraStatus }> = ({ status }) => {
  const config = {
    online:    { color: '#22c55e', label: '온라인', icon: '●' },
    offline:   { color: '#ef4444', label: '오프라인', icon: '●' },
    recording: { color: '#3b82f6', label: '녹화중', icon: '◉' },
    error:     { color: '#f59e0b', label: '오류', icon: '▲' },
  };

  const { color, label, icon } = config[status];

  return (
    <span style={{ color, fontSize: '12px', display: 'flex', alignItems: 'center', gap: '4px' }}>
      <span style={{ animation: status === 'recording' ? 'pulse 1.5s infinite' : 'none' }}>
        {icon}
      </span>
      {label}
    </span>
  );
};
```

### 5-3. SSE 기반 실시간 상태 수신

mmp-server에서 SSE(Server-Sent Events)로 카메라 상태 변경을 푸시한다.

```typescript
// 프론트엔드: SSE 연결
const eventSource = new EventSource('/api/events/cameras');

eventSource.addEventListener('camera-status', (event) => {
  const data = JSON.parse(event.data);
  // { cameraId: 1, status: 'offline', timestamp: '...' }
  updateCameraStatus(data.cameraId, data.status);
});
```

## 6. 이벤트 알림 UI (토스트, 배지, 사운드)

### 6-1. 알림 우선순위

| 우선순위 | 유형 | 표시 방법 |
|---------|------|----------|
| Critical | 카메라 오프라인, 디스크 부족 | 모달 + 사운드 + 배지 |
| Warning | 녹화 중단, 네트워크 불안정 | 토스트 + 배지 |
| Info | 녹화 시작, PTZ 이동 완료 | 토스트 |

### 6-2. 토스트 알림 컴포넌트

```tsx
import { toast } from 'react-hot-toast';

function showCameraAlert(cameraName: string, status: string) {
  if (status === 'offline') {
    toast.error(`${cameraName} 연결 끊김`, {
      duration: 10000,
      icon: '🔴',
      style: { background: '#1f2937', color: '#e5e7eb', border: '1px solid #ef4444' },
    });
    playAlertSound('critical');
  } else if (status === 'online') {
    toast.success(`${cameraName} 연결 복구`, {
      duration: 5000,
      style: { background: '#1f2937', color: '#e5e7eb' },
    });
  }
}
```

### 6-3. 알림 사운드 관리

```typescript
const alertSounds = {
  critical: '/sounds/alert-critical.mp3',
  warning: '/sounds/alert-warning.mp3',
  info: '/sounds/alert-info.mp3',
};

function playAlertSound(level: keyof typeof alertSounds) {
  const audio = new Audio(alertSounds[level]);
  audio.volume = 0.5;
  audio.play().catch(() => {}); // 자동 재생 정책 대응
}
```

## 7. PTZ 제어 UI 설계

### 7-1. 가상 조이스틱 레이아웃

```
        ┌─────────────────────┐
        │       [  ↑  ]       │
        │  [ ← ] [Stop] [ → ]│   [ + ] Zoom In
        │       [  ↓  ]       │   [ - ] Zoom Out
        ├─────────────────────┤
        │ 속도: [===●===]     │   Speed Slider
        ├─────────────────────┤
        │ [P1] [P2] [P3] [H] │   Presets / Home
        └─────────────────────┘
```

### 7-2. 마우스 이벤트 기반 제어

PTZ 버튼은 `mousedown` 시 이동을 시작하고, `mouseup` 시 정지하는 ContinuousMove 방식이다.

```tsx
const PtzButton: React.FC<{ direction: string; onMove: () => void; onStop: () => void }> = (
  { direction, onMove, onStop }
) => (
  <button
    onMouseDown={onMove}
    onMouseUp={onStop}
    onMouseLeave={onStop}
    onTouchStart={onMove}
    onTouchEnd={onStop}
    className="ptz-btn"
    aria-label={`PTZ ${direction}`}
  >
    {direction}
  </button>
);
```

## 9. 접근성(a11y) 고려사항

### 9-1. WCAG 2.1 준수 항목

| 항목 | 수준 | 적용 |
|------|------|------|
| 색상 대비 | AA | 텍스트 대비율 4.5:1 이상 |
| 키보드 탐색 | A | 모든 기능 키보드로 접근 가능 |
| 스크린 리더 | A | aria-label, role 속성 부여 |
| 포커스 표시 | AA | 포커스 링 시각적 표시 |

### 9-2. ARIA 속성 적용 예시

```tsx
<div role="grid" aria-label="CCTV 카메라 그리드">
  <div role="row">
    <div role="gridcell" aria-label="카메라 1 - 온라인" tabIndex={0}>
      <video aria-label="카메라 1 실시간 영상" />
      <StatusBadge status="online" />
    </div>
  </div>
</div>

<nav aria-label="PTZ 카메라 제어">
  <button aria-label="위로 이동">↑</button>
  <button aria-label="왼쪽으로 이동">←</button>
  <button aria-label="정지">Stop</button>
  <button aria-label="오른쪽으로 이동">→</button>
  <button aria-label="아래로 이동">↓</button>
</nav>
```

### 9-3. 키보드 단축키 목록

| 단축키 | 기능 |
|--------|------|
| `1` / `2` / `3` / `4` | 그리드 모드 전환 |
| `F` | 선택 카메라 풀스크린 |
| `ESC` | 풀스크린 해제 |
| `Tab` | 카메라 셀 간 이동 |
| `Space` | 선택 카메라 스냅샷 |
| `R` | 선택 카메라 수동 녹화 시작/중지 |
