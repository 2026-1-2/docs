# React 대시보드 컴포넌트 설계

## 1. 개요

버티포트 CCTV 감시 시스템의 프론트엔드는 React + TypeScript로 구성된다.
Dockview 라이브러리를 활용하여 유연한 패널 레이아웃의 대시보드를 구현한다.

---

## 2. 기술 스택

| 기술 | 버전 | 용도 |
|------|------|------|
| React | 18.x | UI 프레임워크 |
| TypeScript | 5.x | 타입 안전성 |
| Vite | 5.x | 빌드 도구 |
| Dockview | latest | 패널 레이아웃 시스템 |

## 4. 대시보드 레이아웃 (Dockview)

Dockview는 VS Code 스타일의 드래그 앤 드롭 패널 레이아웃을 제공하는 라이브러리이다.

### 4-1. 패널 구성

```
┌─────────────────────────────────────────────────┐
│ Header (MMP Logo, 시스템 상태, 사용자 정보)       │
├──────────┬──────────────────────────────────────┤
│          │  ┌──────────┬──────────┐             │
│ Sidebar  │  │ Camera 1 │ Camera 2 │  Camera Wall│
│          │  ├──────────┼──────────┤             │
│ - 대시보드│  │ Camera 3 │ Camera 4 │             │
│ - 장치   │  └──────────┴──────────┘             │
│ - 녹화   │  ┌────────────────────┬─────────────┤
│ - 로그   │  │ Telemetry Panel    │ PTZ Control │
│ - 설정   │  │ (기상/센서 데이터)  │ (카메라 조작)│
│          │  └────────────────────┴─────────────┤
│          │  ┌──────────────────────────────────┤
│          │  │ Live Events Bar (실시간 이벤트)    │
│          │  └──────────────────────────────────┤
└──────────┴──────────────────────────────────────┘
```

### 4-2. Dockview 사용 방법

```tsx
import { DockviewReact, DockviewReadyEvent } from 'dockview';

function DockviewDashboard() {
  const onReady = (event: DockviewReadyEvent) => {
    const api = event.api;

    api.addPanel({
      id: 'camera-wall',
      component: 'cameraWall',
      title: '카메라 월',
    });

    api.addPanel({
      id: 'telemetry',
      component: 'telemetry',
      title: '원격 측정',
      position: { referencePanel: 'camera-wall', direction: 'below' },
    });
  };

  return (
    <DockviewReact
      onReady={onReady}
      components={{
        cameraWall: CameraWallPanel,
        telemetry: TelemetryPanel,
      }}
    />
  );
}
```

## 5. 주요 컴포넌트

### 5-1. CameraFeed

카메라 한 대의 영상을 표시하는 컴포넌트. WebRTC 또는 HLS로 스트리밍을 수신한다.

```tsx
interface CameraFeedProps {
  streamUrl: string;
  protocol: 'webrtc' | 'hls';
  cameraName: string;
}
```

### 5-2. WebRtcPlayer

WebRTC WHEP 프로토콜을 통해 MediaMTX에서 영상을 수신하는 플레이어.

```tsx
function WebRtcPlayer({ url }: { url: string }) {
  const videoRef = useRef<HTMLVideoElement>(null);

  useEffect(() => {
    const pc = new RTCPeerConnection();
    pc.addTransceiver('video', { direction: 'recvonly' });

    pc.ontrack = (event) => {
      if (videoRef.current) {
        videoRef.current.srcObject = event.streams[0];
      }
    };

    // SDP 교환
    pc.createOffer()
      .then(offer => pc.setLocalDescription(offer))
      .then(() => fetch(url, {
        method: 'POST',
        headers: { 'Content-Type': 'application/sdp' },
        body: pc.localDescription!.sdp,
      }))
      .then(res => res.text())
      .then(sdp => pc.setRemoteDescription({ type: 'answer', sdp }));

    return () => pc.close();
  }, [url]);

  return <video ref={videoRef} autoPlay muted />;
}
```

### 5-3. HlsPlayer

HLS 폴백 플레이어. WebRTC 연결 실패 시 사용.

```tsx
import Hls from 'hls.js';

function HlsPlayer({ url }: { url: string }) {
  const videoRef = useRef<HTMLVideoElement>(null);

  useEffect(() => {
    if (!videoRef.current) return;

    if (Hls.isSupported()) {
      const hls = new Hls();
      hls.loadSource(url);
      hls.attachMedia(videoRef.current);
      return () => hls.destroy();
    }
  }, [url]);

  return <video ref={videoRef} autoPlay muted />;
}
```

### 5-4. PtzControl

PTZ(Pan/Tilt/Zoom) 카메라 제어 UI. 방향 버튼과 줌 슬라이더로 구성.

### 5-5. TelemetryPanel

기상 데이터, 센서 데이터를 실시간으로 표시하는 패널.

## 6. 상태 관리 (Zustand)

```typescript
import { create } from 'zustand';

interface LayoutStore {
  selectedCamera: string | null;
  setSelectedCamera: (id: string | null) => void;
  sidebarCollapsed: boolean;
  toggleSidebar: () => void;
}

const useLayoutStore = create<LayoutStore>((set) => ({
  selectedCamera: null,
  setSelectedCamera: (id) => set({ selectedCamera: id }),
  sidebarCollapsed: false,
  toggleSidebar: () => set((state) => ({ sidebarCollapsed: !state.sidebarCollapsed })),
}));
```

Zustand는 Redux보다 보일러플레이트가 적고, 작은 스토어 단위로 분리하기 쉽다.

## 7. API 통신

```typescript
// services/streams.ts
const API_BASE = import.meta.env.VITE_API_URL || 'http://localhost:3000';

export async function getStreamChannels() {
  const response = await fetch(`${API_BASE}/streams/channels`);
  return response.json();
}

export async function getStreamStatus(path: string) {
  const response = await fetch(`${API_BASE}/streams/status/${path}`);
  return response.json();
}
```

환경 변수 `VITE_API_URL`로 API 서버 주소를 설정한다.
`.env.example`에 예시를 기록하여 팀원 간 설정 공유를 용이하게 한다.
