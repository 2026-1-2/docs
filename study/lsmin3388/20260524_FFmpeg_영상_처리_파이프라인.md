# FFmpeg 영상 처리 파이프라인

## 1. FFmpeg이란?

FFmpeg은 오픈소스 멀티미디어 프레임워크로, 영상/음성의 디코딩, 인코딩, 트랜스코딩, 먹싱, 스트리밍 등 거의 모든 미디어 처리를 수행할 수 있다.

프로젝트에서는 CCTV 카메라의 RTSP 스트림을 MP4 파일로 세그먼트 녹화하는 데 사용한다.

---

## 2. FFmpeg 핵심 도구

| 도구 | 용도 |
|------|------|
| `ffmpeg` | 미디어 변환/녹화/스트리밍 |
| `ffprobe` | 미디어 정보 분석 |
| `ffplay` | 미디어 재생 |

---

## 3. 기본 명령어 구조

```bash
ffmpeg [입력 옵션] -i [입력] [출력 옵션] [출력]
```

### 3-1. RTSP 스트림 정보 확인

```bash
ffprobe -rtsp_transport tcp \
  -i rtsp://admin:password@192.168.0.101:554/Streaming/Channels/101
```

출력 예시:
```
Stream #0:0: Video: h264 (Main), yuv420p, 1920x1080, 25 fps
Stream #0:1: Audio: aac, 16000 Hz, mono
```

### 3-2. 단순 녹화 (코덱 복사)

```bash
ffmpeg -rtsp_transport tcp \
  -i rtsp://admin:password@192.168.0.101:554/Streaming/Channels/101 \
  -c copy \
  -t 60 \
  output.mp4
```

- `-c copy`: 트랜스코딩 없이 원본 코덱 그대로 저장 (CPU 사용량 최소)
- `-t 60`: 60초 녹화

## 4. 세그먼트 녹화

### 4-1. 시간 기반 세그먼트

```bash
ffmpeg -rtsp_transport tcp \
  -i rtsp://admin:password@192.168.0.101:554/Streaming/Channels/101 \
  -c copy \
  -f segment \
  -segment_time 300 \
  -segment_format mp4 \
  -strftime 1 \
  /recordings/cam1/%Y%m%d_%H%M%S.mp4
```

- `-segment_time 300`: 5분(300초)마다 파일 분할
- `-strftime 1`: 파일명에 타임스탬프 사용
- 출력 예: `20260524_143000.mp4`, `20260524_143500.mp4`

### 4-2. 키프레임 기반 분할

```bash
-segment_time 300 \
-reset_timestamps 1 \
-break_non_keyframes 0
```

`-break_non_keyframes 0`: 키프레임(I-frame) 위치에서만 파일을 분할하여 영상 깨짐을 방지한다.

### 5-1. recorder.py 핵심 로직

```python
import subprocess
import os
from datetime import datetime

class Recorder:
    def __init__(self, camera_name, rtsp_url, output_dir, segment_time=300):
        self.camera_name = camera_name
        self.rtsp_url = rtsp_url
        self.output_dir = output_dir
        self.segment_time = segment_time
        self.process = None

    def start(self):
        os.makedirs(self.output_dir, exist_ok=True)
        output_pattern = os.path.join(self.output_dir, '%Y%m%d_%H%M%S.mp4')

        cmd = [
            'ffmpeg',
            '-rtsp_transport', 'tcp',
            '-i', self.rtsp_url,
            '-c', 'copy',
            '-f', 'segment',
            '-segment_time', str(self.segment_time),
            '-segment_format', 'mp4',
            '-strftime', '1',
            '-reset_timestamps', '1',
            output_pattern,
        ]

        self.process = subprocess.Popen(
            cmd,
            stdout=subprocess.PIPE,
            stderr=subprocess.PIPE,
        )

    def stop(self):
        if self.process:
            self.process.terminate()
            self.process.wait()
```

## 6. 트랜스코딩 vs 리먹싱

| 방식 | 설명 | CPU 사용량 | 용도 |
|------|------|-----------|------|
| 리먹싱 (`-c copy`) | 코덱 변경 없이 컨테이너만 변경 | 매우 낮음 | 녹화 저장 |
| 트랜스코딩 | 코덱 변환 (H.265→H.264 등) | 매우 높음 | 브라우저 호환 |

```bash
# 리먹싱 (RTSP → MP4, 코덱 그대로)
ffmpeg -i rtsp://... -c copy output.mp4

# 트랜스코딩 (H.265 → H.264)
ffmpeg -i rtsp://... -c:v libx264 -preset fast output.mp4
```

프로젝트에서는 카메라가 H.264를 사용하므로 리먹싱만으로 충분하다.

---

## 7. 하드웨어 가속

대규모 트랜스코딩이 필요한 경우 GPU 가속을 활용한다.

```bash
# NVIDIA GPU (NVENC)
ffmpeg -i input.mp4 -c:v h264_nvenc -preset fast output.mp4

# Intel Quick Sync Video (VAAPI)
ffmpeg -vaapi_device /dev/dri/renderD128 -i input.mp4 \
  -c:v h264_vaapi output.mp4
```

## 8. 스냅샷 캡처

이벤트 발생 시 현재 프레임을 이미지로 캡처하는 데 사용할 수 있다.

```bash
# 현재 프레임 1장 캡처
ffmpeg -rtsp_transport tcp \
  -i rtsp://admin:password@192.168.0.101:554/Streaming/Channels/101 \
  -vframes 1 \
  -f image2 \
  snapshot.jpg
```

파이프라인으로 사용 시:
```bash
ffmpeg -rtsp_transport tcp -i rtsp://... -vframes 1 -f image2 pipe:1
```

stdout으로 이미지 바이너리를 출력하여 Python에서 직접 메모리에서 처리할 수 있다.

## 9. 녹화 파일 관리 전략

- 5분 단위 세그먼트로 파일을 분할하여 한 파일이 너무 커지는 것을 방지
- 날짜별 디렉토리 구조: `/recordings/cam1/20260524/`
- 디스크 용량 관리를 위해 일정 기간(7일, 30일 등) 이후 자동 삭제 스크립트 운영
- 녹화 파일 메타데이터(시작 시간, 종료 시간, 파일 크기)를 DB에 기록하여 VOD 검색 지원
