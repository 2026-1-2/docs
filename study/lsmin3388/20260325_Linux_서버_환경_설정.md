# Linux(Ubuntu) 서버 환경 설정

## 학습 일자
2026.03.25

## 개요
버티포트 CCTV 감시 시스템은 VMware 기반 Ubuntu 서버에서 Docker 컨테이너로 NestJS, MySQL, MediaMTX를 운영한다. 본 문서에서는 서버 초기 설정부터 Docker 설치, 서비스 등록, 자동화, 모니터링까지 정리한다.

---

## 1. Ubuntu 서버 초기 설정

### 1.1 사용자 생성 및 SSH 설정

```bash
# 사용자 생성 및 권한 부여
sudo adduser vertiport
sudo usermod -aG sudo vertiport
sudo usermod -aG docker vertiport
```

```bash
# SSH 설정 (/etc/ssh/sshd_config)
Port 2222
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes
```

```bash
# SSH 키 등록 (로컬에서)
ssh-keygen -t ed25519 -C "vertiport-server"
ssh-copy-id -p 2222 vertiport@192.168.0.100
sudo systemctl restart sshd
```

### 1.2 방화벽(UFW) 설정

```bash
sudo ufw enable
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 2222/tcp    # SSH
sudo ufw allow 80/tcp      # Nginx
sudo ufw allow 443/tcp     # HTTPS
sudo ufw allow 3000/tcp    # NestJS API
sudo ufw allow from 192.168.0.0/24 to any port 3306  # MySQL (내부망)
sudo ufw allow 8888/tcp    # MediaMTX HLS
sudo ufw allow 8889/tcp    # MediaMTX WebRTC
```

| 포트 | 서비스 | 접근 범위 |
|------|--------|-----------|
| 2222 | SSH | 전체 |
| 80/443 | Nginx | 전체 |
| 3000 | NestJS API | 전체 |
| 3306 | MySQL | 내부망(192.168.0.0/24) |
| 8554 | RTSP (MediaMTX) | 내부망 |
| 8888 | HLS (MediaMTX) | 전체 |
| 8889 | WebRTC (MediaMTX) | 전체 |

## 2. Docker 설치

```bash
# 필요 패키지 설치
sudo apt update
sudo apt install -y ca-certificates curl gnupg lsb-release

# Docker GPG 키 및 저장소 등록
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | \
  sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg

echo "deb [arch=$(dpkg --print-architecture) \
  signed-by=/etc/apt/keyrings/docker.gpg] \
  https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# Docker 설치 및 자동 시작
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io \
  docker-buildx-plugin docker-compose-plugin
sudo systemctl enable docker
```

## 3. systemd 서비스 등록

서버 재부팅 시 Docker Compose 스택을 자동 시작한다.

```ini
# /etc/systemd/system/vertiport.service
[Unit]
Description=Vertiport CCTV Monitoring System
Requires=docker.service
After=docker.service network-online.target

[Service]
Type=oneshot
RemainAfterExit=yes
WorkingDirectory=/home/vertiport/vertiport-system
ExecStart=/usr/bin/docker compose -f docker-compose.prod.yml up -d
ExecStop=/usr/bin/docker compose -f docker-compose.prod.yml down
TimeoutStartSec=120
User=vertiport

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable vertiport.service
sudo systemctl start vertiport.service
sudo journalctl -u vertiport.service -f   # 로그 확인
```

## 4. crontab 자동화

```cron
# 매일 03:00 - 7일 이상 된 녹화 영상 삭제
0 3 * * * find /home/vertiport/recordings -name "*.mp4" -mtime +7 -delete

# 매시간 - 디스크 사용량 90% 초과 알림
0 * * * * /home/vertiport/scripts/check_disk.sh

# 매주 일요일 04:00 - Docker 미사용 리소스 정리
0 4 * * 0 docker system prune -af --volumes >> /var/log/docker-prune.log 2>&1

# 매일 자정 - MySQL 백업
0 0 * * * /home/vertiport/scripts/backup_db.sh

# 5분마다 - MediaMTX 헬스체크
*/5 * * * * /home/vertiport/scripts/healthcheck.sh
```

### 디스크 체크 스크립트 (check_disk.sh)

```bash
#!/bin/bash
THRESHOLD=90
USAGE=$(df / | awk 'NR==2 {print $5}' | tr -d '%')
[ "$USAGE" -gt "$THRESHOLD" ] && \
  echo "[$(date)] WARNING: 디스크 ${USAGE}%" >> /var/log/disk_alert.log
```

## 5. 디스크 모니터링 및 네트워크 진단

```bash
# 디스크 모니터링
df -h                                      # 파일시스템 전체 용량
du -sh /home/vertiport/vertiport-system/*  # 프로젝트 디렉토리별 용량
docker system df                           # Docker 리소스 용량

# 네트워크 진단
ss -tlnp                         # 열린 TCP 포트 확인 (netstat 대체)
ip addr show                     # 네트워크 인터페이스 확인
nc -zv 192.168.1.64 554          # Hikvision 카메라 RTSP 연결 테스트
```

## 6. 프로젝트 서버 구성 (VMware 환경)

| 항목 | 사양 |
|------|------|
| 가상화 | VMware Workstation 17 Pro |
| OS | Ubuntu 22.04 LTS Server |
| CPU / RAM | 4 vCPU / 8GB |
| 디스크 | 시스템 100GB + 녹화 500GB |

```
Host PC ── VMware NAT (192.168.0.0/24)
              └── Ubuntu VM (.100)
                    ├── nestjs-api  (:3000)
                    ├── mysql       (:3306)
                    ├── mediamtx    (:8554,:8888,:8889)
                    └── nginx       (:80,:443)
Hikvision Camera (192.168.1.64) ──RTSP──► mediamtx
```

```bash
# 시간 동기화 (녹화 타임스탬프 정확성 필수)
```
