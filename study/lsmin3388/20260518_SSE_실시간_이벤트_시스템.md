# SSE 기반 실시간 이벤트 알림 시스템

## 1. SSE(Server-Sent Events)란?

SSE는 서버에서 클라이언트로 단방향 실시간 데이터를 전송하는 HTTP 기반 기술이다.
WebSocket과 달리 HTTP/1.1 위에서 동작하며, 서버→클라이언트 방향의 이벤트 스트리밍에 특화되어 있다.

---

## 2. WebSocket vs SSE

| 항목 | WebSocket | SSE |
|------|-----------|-----|
| 통신 방향 | 양방향 | 단방향 (서버→클라이언트) |
| 프로토콜 | ws:// (별도 프로토콜) | HTTP |
| 재연결 | 수동 구현 필요 | 자동 재연결 내장 |
| 브라우저 지원 | 모든 브라우저 | 모든 브라우저 (IE 제외) |
| 프록시/방화벽 | 문제 발생 가능 | HTTP라 문제 없음 |
| 데이터 형식 | 바이너리/텍스트 | 텍스트 (UTF-8) |
| 구현 복잡도 | 높음 | 낮음 |

프로젝트에서는 이벤트 감지 알림이 서버→클라이언트 단방향이므로 SSE가 적합하다.

---

## 3. SSE 프로토콜 형식

```http
HTTP/1.1 200 OK
Content-Type: text/event-stream
Cache-Control: no-cache
Connection: keep-alive

event: detection
data: {"cameraId":"cam1","type":"fielddetection","timestamp":"2026-05-18T14:30:05+09:00"}

event: detection
data: {"cameraId":"cam2","type":"linedetection","timestamp":"2026-05-18T14:30:12+09:00"}
```

각 이벤트는 빈 줄(`\n\n`)로 구분된다.
`event:` 필드로 이벤트 타입을 지정하고, `data:` 필드에 JSON 데이터를 담는다.

## 4. NestJS SSE 구현

### 4-1. EventBusService

내부 이벤트 버스를 통해 감지 이벤트를 SSE 컨트롤러로 전달한다.

```typescript
@Injectable()
export class EventBusService {
  private subject = new Subject<DetectionEvent>();

  emit(event: DetectionEvent) {
    this.subject.next(event);
  }

  subscribe(): Observable<DetectionEvent> {
    return this.subject.asObservable();
  }
}
```

RxJS의 `Subject`를 사용하여 Pub/Sub 패턴을 구현한다.

### 4-2. SSE Controller

```typescript
@Controller('events')
export class SseController {
  constructor(private readonly eventBus: EventBusService) {}

  @Sse('stream')
  stream(): Observable<MessageEvent> {
    return this.eventBus.subscribe().pipe(
      map((event) => ({
        type: 'detection',
        data: JSON.stringify(event),
      } as MessageEvent)),
    );
  }
}
```

`@Sse()` 데코레이터를 사용하면 NestJS가 자동으로 `Content-Type: text/event-stream` 헤더를 설정한다.

### 4-3. DetectionService

Hikvision 카메라의 alertStream에서 이벤트를 수신하여 EventBus로 발행한다.

```typescript
@Injectable()
export class DetectionService implements OnModuleInit {
  constructor(private readonly eventBus: EventBusService) {}

  onModuleInit() {
    this.connectAlertStream();
  }

  private async connectAlertStream() {
    // alertStream XML 파싱 후 이벤트 발행
    this.eventBus.emit({
      cameraId: 'cam1',
      type: 'fielddetection',
      timestamp: new Date().toISOString(),
    });
  }
}
```

## 5. React 클라이언트 구현

### 5-1. EventSource API

```typescript
function useLiveEvents() {
  const [events, setEvents] = useState<DetectionEvent[]>([]);

  useEffect(() => {
    const eventSource = new EventSource('http://localhost:3000/events/stream');

    eventSource.addEventListener('detection', (e) => {
      const event = JSON.parse(e.data);
      setEvents(prev => [event, ...prev].slice(0, 50));
    });

    eventSource.onerror = () => {
      // 자동 재연결됨 (SSE 내장 기능)
      console.log('SSE 연결 끊김, 자동 재연결 중...');
    };

    return () => eventSource.close();
  }, []);

  return events;
}
```

### 5-2. LiveEventsBar 컴포넌트

```tsx
function LiveEventsBar() {
  const events = useLiveEvents();

  return (
    <div className="live-events-bar">
      {events.map((event, i) => (
        <div key={i} className="event-item">
          <span className="event-type">{event.type}</span>
          <span className="event-camera">{event.cameraId}</span>
          <span className="event-time">{event.timestamp}</span>
        </div>
      ))}
    </div>
  );
}
```

## 7. 연결 관리

### 7-1. 하트비트 (Heartbeat)

클라이언트 연결이 끊어졌는지 감지하기 위해 주기적으로 빈 이벤트를 전송한다.

```typescript
@Sse('stream')
stream(): Observable<MessageEvent> {
  const heartbeat$ = interval(30000).pipe(
    map(() => ({ type: 'heartbeat', data: '' } as MessageEvent)),
  );

  const events$ = this.eventBus.subscribe().pipe(
    map((event) => ({ type: 'detection', data: JSON.stringify(event) } as MessageEvent)),
  );

  return merge(heartbeat$, events$);
}
```

### 7-2. 자동 재연결

SSE의 `EventSource`는 연결이 끊어지면 자동으로 재연결을 시도한다.
서버에서 `retry:` 필드를 통해 재연결 간격을 제어할 수 있다.

```
retry: 5000
```

## 8. SSE vs WebSocket 선택 기준

프로젝트에서 SSE를 선택한 이유:
1. 이벤트 알림은 서버→클라이언트 단방향이므로 양방향 통신이 불필요
2. HTTP 기반이라 프록시, 방화벽 환경에서 안정적
3. 자동 재연결 내장으로 구현이 단순
4. NestJS에서 `@Sse()` 데코레이터로 간단히 구현 가능
