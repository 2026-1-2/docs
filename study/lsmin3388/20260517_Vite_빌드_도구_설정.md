# Vite 빌드 도구 설정 및 최적화

> **작성일**: 2026-05-17
> **작성자**: lsmin3388
> **프로젝트**: 버티포트 CCTV 감시 시스템

## 1. 개요

버티포트 CCTV 감시 시스템 프론트엔드는 **React + TypeScript** 기반이며, 빌드 도구로 **Vite**를 사용한다. Vite는 ES Modules 기반의 초고속 개발 서버와 Rollup 기반의 최적화된 프로덕션 빌드를 제공한다.

## 2. Vite vs Webpack vs CRA 비교

| 항목 | Vite | Webpack (CRA) | Webpack (수동) |
|------|------|---------------|---------------|
| 개발 서버 시작 | ~300ms | ~10-30s | ~5-20s |
| HMR 속도 | ~50ms | ~1-5s | ~0.5-3s |
| 번들러 (Dev/Prod) | esbuild / Rollup | Webpack | Webpack |
| 트리 셰이킹 | Rollup 네이티브 | Webpack 5 | Webpack 5 |
| TypeScript | esbuild 즉시 변환 | ts-loader/babel | ts-loader/babel |

**선택 이유**: 카메라 피드 UI 개발 시 빈번한 재시작에 유리, Docker 빌드 파이프라인 간소화, CRA 지원 중단.

## 3. Vite 동작 원리

### 3.1 개발 서버 (ESM 기반)

```
[브라우저] ──> GET /src/App.tsx ──> [Vite Dev Server] ──> esbuild TSX→JS 변환
[브라우저] <── ES Module 응답 ←── import 구문 분석 후 추가 모듈 요청
```

1. 브라우저가 `<script type="module" src="/src/main.tsx">`를 로드
2. Vite가 esbuild로 트랜스파일하여 ES Module로 응답
3. `node_modules` 의존성은 최초 1회 **사전 번들링**(Pre-bundling)하여 `.vite/deps`에 캐싱

### 3.2 프로덕션 빌드

```
소스 코드 → Rollup 번들링 → 트리 셰이킹 → 코드 스플리팅 → 압축(Terser) → dist/
```

## 4. vite.config.ts 주요 설정

```typescript
// vite.config.ts
import { defineConfig, loadEnv } from 'vite';
import react from '@vitejs/plugin-react';
import path from 'path';

export default defineConfig(({ mode }) => ({
  plugins: [react()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
      '@components': path.resolve(__dirname, './src/components'),
      '@hooks': path.resolve(__dirname, './src/hooks'),
      '@services': path.resolve(__dirname, './src/services'),
    },
  },
  server: {
    port: 5173,
    host: true,           // Docker 컨테이너 외부 접근 허용
    strictPort: true,
  },
  build: {
    outDir: 'dist',
    sourcemap: mode === 'development',
    target: 'es2020',
    minify: 'terser',
    terserOptions: { compress: { drop_console: mode === 'production' } },
  },
}));
```

경로 별칭은 `tsconfig.json`에도 동일하게 설정해야 IDE 지원이 된다.

```json
{ "compilerOptions": { "baseUrl": ".", "paths": { "@/*": ["src/*"] } } }
```

## 5. 환경 변수 (VITE_ 접두사)

Vite는 보안을 위해 `VITE_` 접두사가 붙은 변수만 클라이언트에 노출한다.

| 변수명 | 클라이언트 접근 | 용도 |
|--------|:---:|------|
| `VITE_API_URL` | O | API 서버 주소 |
| `VITE_WS_URL` | O | WebSocket 주소 |
| `VITE_MEDIAMTX_URL` | O | MediaMTX 서버 주소 |
| `DATABASE_URL` | X | DB 연결 문자열 |
| `JWT_SECRET` | X | JWT 비밀키 |

```env
# .env.development
VITE_API_URL=http://localhost:3000/api
VITE_WS_URL=ws://localhost:3000
VITE_MEDIAMTX_URL=http://localhost:8889

# .env.production
VITE_API_URL=https://vertiport.knu.ac.kr/api
VITE_WS_URL=wss://vertiport.knu.ac.kr
VITE_MEDIAMTX_URL=https://vertiport.knu.ac.kr/stream
```

```typescript
// src/env.d.ts - 타입 안전한 환경 변수
/// <reference types="vite/client" />
interface ImportMetaEnv {
  readonly VITE_API_URL: string;
  readonly VITE_WS_URL: string;
  readonly VITE_MEDIAMTX_URL: string;
}
```

## 6. 프록시 설정 (server.proxy)

```typescript
server: {
  proxy: {
    '/api': { target: 'http://localhost:3000', changeOrigin: true },
    '/api/events/stream': {
      target: 'http://localhost:3000',
      changeOrigin: true,
      configure: (proxy) => {
        proxy.on('proxyRes', (proxyRes) => {
          proxyRes.headers['x-accel-buffering'] = 'no'; // SSE 버퍼링 방지
        });
      },
    },
    '/webrtc': { target: 'http://localhost:8889', changeOrigin: true, ws: true },
    '/hls': { target: 'http://localhost:8888', changeOrigin: true },
  },
},
```

| 프론트 경로 | 프록시 대상 | 용도 |
|-------------|-----------|------|
| `/api/*` | `localhost:3000` | NestJS REST API |
| `/api/events/stream` | `localhost:3000` | SSE 실시간 이벤트 |
| `/webrtc/*` | `localhost:8889` | MediaMTX WebRTC |
| `/hls/*` | `localhost:8888` | MediaMTX HLS 스트리밍 |

## 7. 빌드 최적화

### 7.1 코드 스플리팅

```typescript
import { lazy, Suspense } from 'react';
const Dashboard = lazy(() => import('@/pages/Dashboard'));
const CameraView = lazy(() => import('@/pages/CameraView'));
const EventLog = lazy(() => import('@/pages/EventLog'));

// 라우터에서 Suspense로 감싸기
<Suspense fallback={<LoadingSpinner />}><Dashboard /></Suspense>
```

### 7.2 청크 분리 (Manual Chunks)

```typescript
build: {
  rollupOptions: {
    output: {
      manualChunks: {
        'vendor-react': ['react', 'react-dom', 'react-router-dom'],
        'vendor-data': ['@tanstack/react-query', 'zustand', 'axios'],
        'vendor-ui': ['@radix-ui/react-dialog', '@radix-ui/react-dropdown-menu'],
      },
    },
  },
},
```

## 8. 정적 에셋 처리

| 에셋 유형 | 크기 기준 | 처리 방식 |
|-----------|----------|-----------|
| 이미지/폰트 | < 4KB | Base64 인라인 |
| 이미지/폰트 | >= 4KB | 파일 복사 + 해시 이름 |
| SVG | - | 컴포넌트 또는 URL import |

`public/` 디렉토리 파일은 빌드 시 `dist/` 루트에 그대로 복사된다 (파비콘, robots.txt 등).

## 9. Docker 멀티스테이지 빌드

```dockerfile
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
EXPOSE 80
```

## 10. 요약

- **Vite**는 ESM 기반 개발 서버로 빠른 시작과 HMR, Rollup 기반 프로덕션 빌드를 제공한다.
- **환경 변수**는 `VITE_` 접두사로 클라이언트 노출 범위를 통제한다.
- **프록시 설정**으로 개발 환경에서 CORS 없이 NestJS, MediaMTX와 통신한다.
- **코드 스플리팅 + 청크 분리**로 초기 로딩 성능을 최적화한다.
- **멀티스테이지 Docker 빌드**로 경량 프로덕션 이미지를 생성한다.
